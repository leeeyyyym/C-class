    반복문 (2) — 잘못된 값을 입력했다면?¶

    🎯 이 장에서 배우는 것¶

    • while + break 조합으로 "최소 1회 실행" 패턴을 구현할 수 있다
    • do-while문의 구조와 동작을 이해하고 사용할 수 있다
    • 사용자가 잘못된 값을 입력했을 때 다시 입력받는 유효성 검사를 작성할 수 있다

    📚 핵심 개념¶

    "일단 한 번은 실행" 패턴¶

    자판기에 동전을 넣었는데 인식이 안 되면 어떻게 하나요? 다시 넣죠.
    동전을 넣는 행위가 최소 한 번은 일어나고, 인식될 때까지 반복됩니다.

    프로그래밍에서도 똑같습니다.
    "일단 입력을 받고, 잘못됐으면 다시 받자"는 패턴이 바로 이것입니다.

    이걸 구현하는 방법이 두 가지 있습니다.

    방법 특징
    while (1) + break 조건을 내가 원하는 곳에 자유롭게 배치
    do-while "최소 1회 실행" 의도가 코드에 명확히 드러남

    방법 1: while (1) + break¶

    while (1) {         // 무한루프 시작
    // 코드 실행
    if (조건) {
        break;      // 조건 만족 시 탈출!
    }
}

    while (1)은 조건이 항상 참(1)이라 영원히 돌아가는 반복문입니다. 탈출하려면 반드시 break가 필요합니다.

    ⚠️ break 없이 while (1)을 쓰면 프로그램이 영원히 끝나지 않습니다! 실수로 빠졌다면 Ctrl + C로 탈출하세요.

    방법 2: do-while문

    do {
    // 코드 실행  ← 조건 확인 전에 무조건 한 번 실행!
} while (조건);     // 조건이 참이면 다시 위로 올라감

    while문과 do-while문의 차이를 그림으로 비교해봅시다.

    [ while문 ] [ do-while문 ]

    조건 확인 ──거짓──▶ 종료 실행 │ │ 참 조건 확인 ──거짓──▶ 종료 │ │ 실행 참 │ │ └────────────────────────────┘ 💡 핵심 차이: while문은 조건이 처음부터 거짓이면 한 번도 실행 안 되지만, do-while문은 무조건 최소 1번은 실행됩니다!

    do-while 문법 주의사항:

    do {
    // 코드
} while (조건);  // ← 세미콜론(;) 필수! 자주 빠뜨리는 실수입니다
🔨 따라하기
Step 1: while (1) + break로 유효한 입력 받기
1 또는 2만 허용하고, 그 외에는 다시 물어보는 코드입니다.
    

    #include <stdio.h>

int main(void) {
    int answer;
while (1) {                          // 무한루프 시작
    printf("선택하세요 (1 또는 2): ");
    scanf("%d", &answer);

    if (answer == 1 || answer == 2) {
        break;                       // 올바른 입력이면 탈출!
    }

    printf("⚠️ 1 또는 2만 입력해주세요. 다시!\n");
    // break 없이 계속 → 자동으로 반복문 처음으로 돌아감
}

printf("입력한 값: %d\n", answer);

return 0;

    


    }

⚠️ 1 또는 2만 입력해주세요. 다시!

⚠️ 1 또는 2만 입력해주세요. 다시!

입력한 값: 1
Step 2: 똑같은 걸 do-while로 바꿔보기
Step 1과 동일한 동작을 do-while로 표현하면 이렇습니다.
    

    #include <stdio.h>

int main(void) {
    int answer;
do {
    printf("선택하세요 (1 또는 2): ");
    scanf("%d", &answer);

    if (answer != 1 && answer != 2) {
        printf("⚠️ 1 또는 2만 입력해주세요. 다시!\n");
    }

} while (answer != 1 && answer != 2);  // 잘못된 입력이면 다시!

printf("입력한 값: %d\n", answer);

return 0;

    


    }
💡 두 코드의 동작은 완전히 같습니다.
do-while은 "올바른 입력이 들어올 때까지 반복한다"는 의도가 더 잘 보이는 장점이 있습니다.
    

    Step 3: MBTI 게임에 유효성 검사 추가하기
지금까지 배운 반복문에 유효성 검사를 넣어서 게임을 완성해봅시다.
    

    #include <stdio.h>

int main(void) {
// 점수와 질문 번호를 저장할 변수
int score = 0;
int answer;
int i;

// 4개의 질문을 순서대로 진행
for (i = 1; i <= 4; i++) {

    // 질문 출력
    if (i == 1) printf("\nQ%d. 혼자 있는 시간이 편하다\n", i);
    else if (i == 2) printf("\nQ%d. 계획 없이 여행을 떠날 수 있다\n", i);
    else if (i == 3) printf("\nQ%d. 논리가 감정보다 중요하다\n", i);
    else if (i == 4) printf("\nQ%d. 마감 직전에 집중력이 올라간다\n", i);

    // 🔒 유효성 검사: 1 또는 2가 입력될 때까지 반복
    do {
        printf("  👉 그렇다(1) / 아니다(2): ");
        scanf("%d", &answer);

        if (answer != 1 && answer != 2) {
            printf("  ⚠️ 1 또는 2만 입력해주세요!\n");
        }

    } while (answer != 1 && answer != 2);

    // 점수 계산
    if (answer == 1) {
        score++;
    }
}

printf("\n✨ 완료! 총 점수: %d / 4\n", score);

return 0;

    


    }

    do-while vs while (1) + break 언제 쓰나요?
    

    상황  추천

✅ 점검하기
1. while문과 do-while문의 가장 큰 차이는 무엇인가요?
    

    while문은 조건이 처음부터 거짓이면 한 번도 실행되지 않지만,
do-while문은 조건과 상관없이 무조건 최소 1번은 실행됩니다.
    

      

    1. 아래 코드에서 빠진 것은 무엇인가요?
      2. 

    

    do {
    printf("숫자를 입력하세요: ");
    scanf("%d", &num);
} while (num < 0)

    

    while (num < 0) 뒤에 세미콜론(;) 이 빠져 있습니다.
    

      

    1. while (1) + break 패턴에서 break를 쓰지 않으면 어떻게 되나요?
      2. 

    

    조건이 항상 참(1)이기 때문에 반복문이 영원히 끝나지 않는 무한루프에 빠집니다.
