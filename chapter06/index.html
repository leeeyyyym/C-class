    배열 — 질문 목록과 점수를 한곳에 저장하기¶

    🎯 이 장에서 배우는 것¶

    • 배열을 선언하고 인덱스로 요소에 접근할 수 있다
    • 문자열 배열과 정수 배열을 활용하여 MBTI 데이터를 저장할 수 있다
    • 배열과 반복문을 결합하여 질문 목록을 효율적으로 관리할 수 있다

    📚 핵심 개념¶

    개념: 배열 (Array)¶

    1. 비유로 시작 🎒

    배열은 마치 번호가 붙은 사물함과 같아요. 사물함 전체에 하나의 이름(scores)을 붙이고, 각 칸은 0번부터 시작하는 번호(인덱스)로 구분합니다. 모든 칸에는 같은 종류의 물건만 넣을 수 있어요.

    2. 정확한 정의

    배열은 같은 자료형의 데이터를 연속된 메모리에 저장하는 구조입니다. 파이썬 리스트와 비슷하지만 두 가지가 다릅니다.

    • 크기를 미리 정해야 합니다 (나중에 늘릴 수 없음)
    • 같은 자료형만 담을 수 있습니다

    3. 예시로 확인

    // 정수 4개를 담는 배열
int scores[4] = {0, 0, 0, 0};

// 인덱스로 접근 (0부터 시작!)
scores[0] = 10;  // 첫 번째 칸에 10 저장
scores[3] = 5;   // 네 번째 칸에 5 저장
    graph LR subgraph "scores 배열" A["[0] → 10"] --- B["[1] → 0"] --- C["[2] → 0"] --- D["[3] → 5"] end

    💡 파이썬과의 차이: 파이썬에서 my_list = [10, 0, 0, 5]처럼 쓰던 것을, C에서는 int scores[4] = {10, 0, 0, 5};로 씁니다. 대괄호 위치와 중괄호 초기화가 핵심!

    🔨 따라하기¶

    Step 1: 질문 배열 만들고 출력하기¶

    MBTI 질문 3개를 문자열 배열로 저장하고, for문으로 순회해봅시다.

    #include <stdio.h>

int main(void) {
    // 문자열 배열: 포인터 배열로 질문 저장
    char *questions[3] = {
        "파티에서 새로운 사람에게 먼저 말을 건다",
        "혼자 있는 시간이 더 편하다",
        "계획 없이 여행을 떠나는 게 좋다"
    };

    // for문으로 질문 출력
    for (int i = 0; i < 3; i++) {
        printf("Q%d. %s\n", i + 1, questions[i]);
    }

    return 0;
}

    실행 결과: 

    Q1. 파티에서 새로운 사람에게 먼저 말을 건다
Q2. 혼자 있는 시간이 더 편하다
Q3. 계획 없이 여행을 떠나는 게 좋다

    Step 2: 점수 배열과 결합하여 응답 누적하기¶

    질문에 대한 응답(1: 예, 0: 아니오)을 받아 점수를 누적합니다.

    #include <stdio.h>

int main(void) {
    char *questions[3] = {
        "파티에서 새로운 사람에게 먼저 말을 건다",
        "혼자 있는 시간이 더 편하다",
        "계획 없이 여행을 떠나는 게 좋다"
    };

    // E/I 점수를 배열로 관리: [0]=E점수, [1]=I점수
    int scores[2] = {0, 0};
    int answer;

    for (int i = 0; i < 3; i++) {
        printf("Q%d. %s\n", i + 1, questions[i]);
        printf("   (1: 예 / 0: 아니오) >> ");
        scanf("%d", &answer);

        if (answer == 1) {
            // 질문 0, 2는 E성향 / 질문 1은 I성향
            if (i == 1) {
                scores[1]++;  // I 점수 증가
            } else {
                scores[0]++;  // E 점수 증가
            }
        }
    }

    printf("\n--- 결과 ---\n");
    printf("E 점수: %d / I 점수: %d\n", scores[0], scores[1]);
    printf("당신은 %c 성향입니다!\n", scores[0] >= scores[1] ? 'E' : 'I');

    return 0;
}

    실행 결과 (예시 입력: 1, 1, 0): 

    Q1. 파티에서 새로운 사람에게 먼저 말을 건다
   (1: 예 / 0: 아니오) >> 1
Q2. 혼자 있는 시간이 더 편하다
   (1: 예 / 0: 아니오) >> 1
Q3. 계획 없이 여행을 떠나는 게 좋다
   (1: 예 / 0: 아니오) >> 0

--- 결과 ---
E 점수: 1 / I 점수: 1
당신은 E 성향입니다!

    ⚠️ 주의할 점¶

    • 인덱스는 0부터 시작! 크기가 3인 배열의 마지막 인덱스는 2입니다. scores[3]에 접근하면 오류가 발생하거나 엉뚱한 값이 나옵니다 (C는 이걸 자동으로 막아주지 않아요 😱)
    • 배열 크기는 변경 불가! int scores[2]로 선언하면 나중에 칸을 추가할 수 없습니다. 처음에 충분한 크기로 선언하세요

    ✅ 점검하기¶

    1. int data[5]에서 유효한 인덱스 범위는?

    정답 확인0부터 4까지입니다. 크기가 5이므로 data[0], data[1], data[2], data[3], data[4]를 사용할 수 있습니다.

    2. 파이썬 리스트와 C 배열의 가장 큰 차이 2가지는?

    정답 확인① C 배열은 크기를 미리 정해야 합니다 (파이썬은 자유롭게 추가 가능). ② C 배열은 같은 자료형만 담을 수 있습니다 (파이썬은 섞어서 가능).

    3. 아래 코드의 출력 결과는? 

    int arr[3] = {10, 20, 30};
arr[1] = arr[0] + arr[2];
printf("%d", arr[1]);

    정답 확인40입니다. arr[0]은 10, arr[2]는 30이므로 10 + 30 = 40이 arr[1]에 저장됩니다.
