    for 반복문 — 질문을 여러 개 돌리자¶

    🎯 이 장에서 배우는 것¶

    • C언어의 for문 구조(초기화; 조건; 증감)를 이해하고 작성할 수 있다
    • for문으로 MBTI 질문 4개를 반복 출력하고 답변을 받는 코드를 작성할 수 있다

    📚 핵심 개념¶

    개념: for 반복문¶

    비유로 시작 🏃

    for문은 운동장 트랙을 정해진 바퀴만큼 도는 것과 같아요. "지금 몇 바퀴째지?"(초기화) → "4바퀴 다 돌았나?"(조건) → "한 바퀴 완료!"(증감)

    정확한 정의

    for문은 세 가지 요소로 반복을 제어합니다.

    for (초기화; 조건; 증감) {
    반복할 코드
}
    • 초기화 int i = 0 → 출발선에 서기 (한 번만 실행)
    • 조건 i < 4 → 계속 달릴까? (매 바퀴 확인)
    • 증감 i++ → 바퀴 수 +1 (매 바퀴 끝에 실행)

    파이썬과 비교 🐍↔️🔧

    graph LR A["🐍 Python<br/>for i in range(4):"] --- B["같은 동작!<br/>i = 0, 1, 2, 3"] B --- C["🔧 C언어<br/>for(int i=0; i<4; i++)"]

    파이썬의 range(4)가 알아서 해주던 것을, C에서는 초기화·조건·증감으로 직접 써주는 것뿐이에요!

    🔨 따라하기¶

    Step 1: 숫자 1~4 출력해보기¶

    #include <stdio.h>

int main(void) {
    for (int i = 1; i <= 4; i++) {   // 1부터 시작, 4까지
        printf("질문 %d번!\n", i);
    }
    return 0;
}

    실행 결과: 

    질문 1번!
질문 2번!
질문 3번!
질문 4번!

    💡 i = 1로 시작하면 질문 번호를 자연스럽게 1번부터 쓸 수 있어요!

    Step 2: MBTI 질문 루프 완성하기¶

    이제 매 반복마다 A/B 입력을 받고, 점수를 누적해봅시다.

    #include <stdio.h>

int main(void) {
    int score = 0;       // E/I 점수 누적용
    char answer;

    for (int i = 1; i <= 4; i++) {
        printf("\n=== 질문 %d번 ===\n", i);
        printf("모임에서 나는? (A: 먼저 말 건다 / B: 기다린다): ");
        scanf(" %c", &answer);   // 공백 주의!

        if (answer == 'A') {
            score++;   // A 선택 시 +1
        }
    }

    printf("\n--- 결과 ---\n");
    printf("A를 %d번 선택했습니다.\n", score);

    if (score >= 3) {
        printf("당신은 E(외향형)에 가깝습니다!\n");
    } else {
        printf("당신은 I(내향형)에 가깝습니다!\n");
    }

    return 0;
}

    실행 결과 (예시): 

    === 질문 1번 ===
모임에서 나는? (A: 먼저 말 건다 / B: 기다린다): A

=== 질문 2번 ===
모임에서 나는? (A: 먼저 말 건다 / B: 기다린다): B

=== 질문 3번 ===
모임에서 나는? (A: 먼저 말 건다 / B: 기다린다): A

=== 질문 4번 ===
모임에서 나는? (A: 먼저 말 건다 / B: 기다린다): A

--- 결과 ---
A를 3번 선택했습니다.
당신은 E(외향형)에 가깝습니다!

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int score = 0;
    char answer;

    for (int i = 1; i <= 4; i++) {
        printf("\n=== 질문 %d번 ===\n", i);
        printf("모임에서 나는? (A: 먼저 말 건다 / B: 기다린다): ");
        scanf(" %c", &answer);

        if (answer == 'A') {
            score++;
        }
    }

    printf("\n--- 결과 ---\n");
    printf("A를 %d번 선택했습니다.\n", score);

    if (score >= 3) {
        printf("당신은 E(외향형)에 가깝습니다!\n");
    } else {
        printf("당신은 I(내향형)에 가깝습니다!\n");
    }

    return 0;
}

    ⚠️ 주의할 점¶

    1. scanf(" %c")에서 %c 앞의 공백을 꼭 넣으세요! 없으면 이전 Enter키가 입력으로 들어가서 질문이 건너뛰어집니다 😱
    2. i++를 빼먹으면 조건이 영원히 참이 되어 무한 반복에 빠집니다. Ctrl+C로 탈출하세요!

    ✅ 점검하기¶

    1. for (int i = 0; i < 4; i++)에서 i는 어떤 값들을 거치나요?

    정답 확인0, 1, 2, 3 (총 4번 반복)

    2. 질문을 4개가 아니라 10개로 늘리려면 코드 어디를 바꾸면 될까요?

    정답 확인i <= 4를 i <= 10으로 바꾸면 됩니다. 이것이 반복문의 힘이에요! 🎉

    3. for문의 세 요소를 순서대로 말해보세요.

    정답 확인초기화 → 조건 → 증감 (예: int i=1; i<=4; i++)
