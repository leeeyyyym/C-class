    문자열 다루기 — MBTI 결과 조합하기¶

    🎯 이 장에서 배우는 것¶

    • C에서 문자열이 char 배열 + 널 종료 문자(\0)임을 이해할 수 있다
    • strlen, strcpy, strcat 함수의 기본 사용법을 알 수 있다
    • E/I, S/N, T/F, J/P 점수를 바탕으로 MBTI 결과 문자열을 조합할 수 있다

    📚 핵심 개념¶

    개념: C 문자열 = char 배열 + \0¶

    비유로 시작 ✨

    문자열은 마치 칸이 나뉜 기차와 같아요. 각 칸에 글자가 하나씩 탑승하고, 맨 마지막 칸에는 "여기가 끝!"이라는 빨간 깃발(\0)이 꽂혀 있습니다. 이 깃발이 없으면 컴퓨터는 기차가 어디서 끝나는지 몰라 엉뚱한 데까지 읽어버려요.

    정확한 정의

    파이썬에서 "ENFP"는 그냥 str 타입이었죠. C에서는 문자(char)들의 배열이 곧 문자열이며, 반드시 끝에 널 문자 \0이 붙어야 합니다.

    char mbti[5] = {'E', 'N', 'F', 'P', '\0'};
// 또는 간단히
char mbti[] = "ENFP";  // 컴파일러가 \0을 자동으로 붙여줌
    graph LR A["[0] 'E'"] --> B["[1] 'N'"] --> C["[2] 'F'"] --> D["[3] 'P'"] --> E["[4] '\\0'"]

    💡 글자 4개인 "ENFP"를 저장하려면 배열 크기가 5 이상이어야 해요!

    자주 쓰는 문자열 함수 (string.h)¶

    #include <string.h>를 추가하면 사용할 수 있습니다.

    • strlen(s) — 문자열 길이 반환 (\0 제외). strlen("ENFP")는 4
    • strcpy(dest, src) — src 문자열을 dest에 복사
    • strcat(dest, src) — dest 뒤에 src를 이어 붙이기

    🔨 따라하기¶

    Step 1: 한 글자씩 MBTI 조합하기¶

    4개 축의 점수를 비교해서, 결과 문자열을 한 글자씩 채워 넣는 방식입니다.

    #include <stdio.h>

int main(void) {
    // 각 축의 점수 (양수면 앞 글자, 음수면 뒷 글자)
    int e_score = 3;   // 양수 → E, 음수 → I
    int s_score = -2;  // 양수 → S, 음수 → N
    int t_score = -1;  // 양수 → T, 음수 → F
    int j_score = 4;   // 양수 → J, 음수 → P

    char result[5];  // 4글자 + \0

    result[0] = (e_score >= 0) ? 'E' : 'I';
    result[1] = (s_score >= 0) ? 'S' : 'N';
    result[2] = (t_score >= 0) ? 'T' : 'F';
    result[3] = (j_score >= 0) ? 'J' : 'P';
    result[4] = '\0';  // 🔴 이걸 빼먹으면 큰일!

    printf("당신의 MBTI는 %s입니다!\n", result);
    return 0;
}

    실행 결과: 

    당신의 MBTI는 ENFJ입니다!

    Step 2: strcat으로 이어 붙이기¶

    이번엔 각 글자를 작은 문자열로 만들어 strcat으로 합쳐봅시다.

    #include <stdio.h>
#include <string.h>

int main(void) {
    int scores[] = {3, -2, -1, 4};
    char pairs[][3] = {"EI", "SN", "TF", "JP"};

    char result[5] = "";  // 빈 문자열로 시작

    for (int i = 0; i < 4; i++) {
        char one_letter[2];  // 글자 1개 + \0
        // 점수 >= 0이면 앞 글자(인덱스 0), 아니면 뒷 글자(인덱스 1)
        one_letter[0] = (scores[i] >= 0) ? pairs[i][0] : pairs[i][1];
        one_letter[1] = '\0';

        strcat(result, one_letter);  // result 뒤에 이어 붙이기
    }

    printf("결과: %s (길이: %lu)\n", result, strlen(result));
    return 0;
}

    실행 결과: 

    결과: ENFJ (길이: 4)

    📝 전체 코드¶

    #include <stdio.h>
#include <string.h>

int main(void) {
    // 4개 축 점수 (양수면 앞 글자, 음수면 뒷 글자)
    int scores[] = {3, -2, -1, 4};
    char pairs[][3] = {"EI", "SN", "TF", "JP"};

    char result[5] = "";

    for (int i = 0; i < 4; i++) {
        char letter[2];
        letter[0] = (scores[i] >= 0) ? pairs[i][0] : pairs[i][1];
        letter[1] = '\0';
        strcat(result, letter);
    }

    printf("🧠 당신의 MBTI는 %s입니다!\n", result);
    printf("문자열 길이: %lu\n", strlen(result));

    return 0;
}

    ⚠️ 주의할 점¶

    1. \0을 빼먹지 마세요! — 널 문자가 없으면 printf나 strlen이 메모리를 넘어서 읽어버립니다. 쓰레기 값이 출력되거나 프로그램이 죽을 수 있어요 💀
    2. 배열 크기를 넉넉히! — strcat은 dest 배열이 충분히 큰지 확인하지 않습니다. char result[5]에 5글자 이상을 넣으면 버퍼 오버플로우가 발생합니다.

    ✅ 점검하기¶

    1. char name[] = "INTJ";에서 배열의 실제 크기는 몇일까요?

    정답 확인5입니다. 글자 4개('I','N','T','J') + 널 문자('\0') 1개 = 총 5칸이 필요합니다.

    2. strlen("Hello")의 반환값은?

    정답 확인5입니다. strlen은 널 문자를 제외한 순수 글자 수만 셉니다.

    3. strcat을 사용하기 전에 dest 문자열이 반드시 갖춰야 할 조건 두 가지는?

    정답 확인① 유효한 문자열이어야 합니다(널 문자로 끝나야 함). ② 이어 붙일 내용까지 담을 수 있도록 배열 크기가 충분해야 합니다.
