    배열 (1) — 질문 목록과 점수를 한 곳에 모으자¶

    Part 3: 게임을 체계적으로 — 함수와 배열

    🎯 이 장에서 배우는 것¶

    • 배열을 선언하고 인덱스로 값을 저장·접근할 수 있다
    • 문자열 배열에 MBTI 질문을 저장하고, 반복문으로 순회하는 코드를 작성할 수 있다

    📚 핵심 개념¶

    개념: 배열 (Array)¶

    1. 비유로 시작 🗄️

    배열은 번호가 붙은 사물함과 같아요. 사물함 0번, 1번, 2번… 각 칸에 같은 종류의 물건(정수면 정수, 문자열이면 문자열)을 넣어두고, 번호(인덱스)만 알면 바로 꺼낼 수 있죠.

    2. 정확한 정의

    배열은 같은 자료형의 값을 고정된 개수만큼 연속으로 저장하는 구조입니다.

    int scores[4];            // 정수 4칸짜리 사물함
char questions[4][100];   // 문자열 4칸짜리 사물함 (각 칸 최대 99자)

    3. 핵심 포인트

    • 🔢 인덱스는 0부터 시작 → 4칸이면 0, 1, 2, 3 (4번 없음!)
    • 📏 크기 고정 → 선언할 때 정한 칸 수를 나중에 늘릴 수 없음
    • 🔒 같은 자료형만 → int 배열에 문자열 저장 불가

    💡 파이썬 리스트는 크기도 자유롭고 여러 타입을 섞을 수 있었죠? C 배열은 더 엄격하지만, 그만큼 빠릅니다!

    🔨 따라하기¶

    Step 1: 질문과 점수를 배열에 담기¶

    지금까지 질문을 printf로 하드코딩했다면, 이제 배열 하나에 모아봅시다.

    #include <stdio.h>
#include <string.h>

int main(void) {
    // 질문 4개를 문자열 배열에 저장
    char questions[4][100] = {
        "혼자보다 여럿이 놀 때 에너지가 난다? (1:Yes 0:No)",
        "구체적 사실이 상상보다 편하다? (1:Yes 0:No)",
        "결정할 때 논리가 감정보다 우선? (1:Yes 0:No)",
        "계획을 세워야 마음이 편하다? (1:Yes 0:No)"
    };

    int scores[4] = {0, 0, 0, 0};  // E/I, S/N, T/F, J/P 점수
    int answer;

    for (int i = 0; i < 4; i++) {   // i = 0, 1, 2, 3
        printf("Q%d: %s\n", i + 1, questions[i]);
        scanf("%d", &answer);
        scores[i] = answer;         // 해당 칸에 점수 저장
    }

    // 결과 출력
    printf("\n당신의 MBTI: ");
    printf("%c", scores[0] ? 'E' : 'I');
    printf("%c", scores[1] ? 'S' : 'N');
    printf("%c", scores[2] ? 'T' : 'F');
    printf("%c", scores[3] ? 'J' : 'P');
    printf("\n");

    return 0;
}

    Step 2: 실행해보기¶

    실행 결과 (입력 예: 1, 0, 1, 0): 

    Q1: 혼자보다 여럿이 놀 때 에너지가 난다? (1:Yes 0:No)
1
Q2: 구체적 사실이 상상보다 편하다? (1:Yes 0:No)
0
Q3: 결정할 때 논리가 감정보다 우선? (1:Yes 0:No)
1
Q4: 계획을 세워야 마음이 편하다? (1:Yes 0:No)
0
당신의 MBTI: ENTP

    for문의 i가 곧 배열 인덱스가 되어, 질문 출력과 점수 저장을 4줄의 반복으로 해결합니다! 🎉

    ⚠️ 주의할 점¶

    • 인덱스 범위 초과 금지! scores[4]에 접근하면 존재하지 않는 5번째 칸을 건드리는 것 → 프로그램이 예측 불가능하게 동작합니다 (C는 경고 없이 실행됨 😱)
    • 문자열 배열의 두 번째 크기 [100] 은 한 문자열의 최대 길이입니다. 질문이 100자를 넘으면 잘릴 수 있으니 넉넉하게 잡으세요.

    ✅ 점검하기¶

    1. int arr[5]에서 사용할 수 있는 인덱스 범위는?

    정답 확인0, 1, 2, 3, 4 — 총 5개이며, arr[5]는 범위 밖입니다.

    2. 배열을 for문과 함께 쓰면 좋은 이유는?

    정답 확인반복 변수 i를 인덱스로 그대로 사용할 수 있어서, 배열의 모든 요소를 간결하게 순회할 수 있기 때문입니다.

    3. char names[3][50]은 어떤 구조인가요?

    정답 확인최대 50자짜리 문자열 3개를 저장할 수 있는 문자열 배열입니다. (인덱스 0, 1, 2)
