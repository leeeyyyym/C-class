    비트연산자 맛보기 — 0과 1의 세계 엿보기¶

    🎯 이 장에서 배우는 것¶

    • 비트(bit)와 2진수 표현을 간단히 설명할 수 있다
    • 기본 비트연산자(&, |, <<, >>)의 동작을 예제로 확인할 수 있다
    • 비트연산이 실제로 어디에 쓰이는지 맥락을 이해할 수 있다

    📚 핵심 개념¶

    개념: 비트(bit)와 비트연산자¶

    1️⃣ 비유로 시작

    비트는 마치 전구 스위치와 같아요. 켜짐(1) 아니면 꺼짐(0), 딱 두 가지뿐이죠!

    스위치 4개를 나란히 놓으면 0101처럼 표현할 수 있고, 이게 바로 2진수입니다. 컴퓨터는 모든 데이터를 이런 0과 1의 조합으로 처리합니다.

    2️⃣ 비트연산자란?

    이 0과 1을 직접 조작하는 연산자입니다.

    • & (AND) — 둘 다 1일 때만 1 → "두 스위치 모두 켜져야 불이 들어와요"
    • | (OR) — 하나라도 1이면 1 → "스위치 하나만 켜도 불이 들어와요"
    • << (왼쪽 시프트) — 비트를 왼쪽으로 밀기 → 값이 2배씩 커져요
    • >> (오른쪽 시프트) — 비트를 오른쪽으로 밀기 → 값이 절반씩 줄어요

    3️⃣ 어디에 쓰이나요?

    아두이노에서 LED 8개를 한 번에 제어하거나, 센서 값의 특정 비트만 읽을 때 비트연산을 씁니다. 우리 MBTI 게임의 4개 축도 비트 하나씩으로 표현할 수 있어요! 🎮

    🔨 따라하기¶

    Step 1: 비트연산자 동작 확인하기¶

    # 2진수 리터럴: 0b로 시작
a = 0b1100  # 10진수 12
b = 0b1010  # 10진수 10

print(f"a     = {a:04b} ({a})")   # 1100
print(f"b     = {b:04b} ({b})")   # 1010
print(f"a & b = {a & b:04b} ({a & b})")  # AND
print(f"a | b = {a | b:04b} ({a | b})")  # OR
print(f"1 << 3 = {1 << 3:04b} ({1 << 3})")  # 왼쪽 시프트
print(f"8 >> 2 = {8 >> 2:04b} ({8 >> 2})")  # 오른쪽 시프트

    실행 결과: 

    a     = 1100 (12)
b     = 1010 (10)
a & b = 1000 (8)
a | b = 1110 (14)
1 << 3 = 1000 (8)
8 >> 2 = 0010 (2)

    Step 2: MBTI를 비트 플래그로 표현하기 🧬¶

    # 각 축을 비트 하나로! (1이면 뒤쪽 유형)
E_I = 1 << 3  # 8 → I
S_N = 1 << 2  # 4 → N
T_F = 1 << 1  # 2 → F
J_P = 1 << 0  # 1 → P

# INFP 만들기: I, N, F, P 모두 켜기
mbti = E_I | S_N | T_F | J_P  # 1111 = 15
print(f"INFP = {mbti:04b} ({mbti})")

# 이 사람이 I(내향)인지 확인
if mbti & E_I:
    print("내향형(I)입니다!")

    실행 결과: 

    INFP = 1111 (15)
내향형(I)입니다!

    📝 전체 코드¶

    # === 비트연산자 맛보기 ===
a = 0b1100
b = 0b1010
print(f"a & b = {a & b:04b}")
print(f"a | b = {a | b:04b}")
print(f"1 << 3 = {1 << 3}")
print(f"8 >> 2 = {8 >> 2}")

# === MBTI 비트 플래그 ===
E_I = 1 << 3
S_N = 1 << 2
T_F = 1 << 1
J_P = 1 << 0

mbti = E_I | S_N | T_F | J_P  # INFP
print(f"INFP = {mbti:04b}")
if mbti & E_I:
    print("내향형(I)입니다!")

    ⚠️ 주의할 점¶

    • 🔸 비트연산자 &(AND)와 논리연산자 and는 다릅니다! 비트연산자는 각 비트를 하나씩 비교해요.
    • 🔸 지금은 "이런 게 있구나" 수준이면 충분합니다. 아두이노 과정에서 실제 하드웨어 제어에 활용하게 됩니다! 😊

    ✅ 점검하기¶

    1. 0b1010 & 0b1100의 결과는 2진수로 무엇일까요?

    정답 확인0b1000 (10진수 8) — 둘 다 1인 자리만 1이 됩니다.

    2. 1 << 4의 10진수 결과는?

    정답 확인16 — 1을 왼쪽으로 4칸 밀면 10000(2) = 16입니다.

    3. 비트연산이 아두이노에서 유용한 이유는?

    정답 확인LED나 센서 핀을 하나씩 켜고 끄는 등, 특정 비트만 정확히 제어할 수 있기 때문입니다.
