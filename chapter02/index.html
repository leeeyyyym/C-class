    변수와 자료형 — 데이터를 담는 그릇의 크기가 정해져 있다고?¶

    🎯 이 장에서 배우는 것¶

    • int, char, float 자료형을 구분하고 변수를 선언할 수 있다
    • 파이썬(동적 타이핑)과 C(정적 타이핑)의 차이를 설명할 수 있다
    • MBTI 게임용 점수 변수를 직접 만들 수 있다

    📚 핵심 개념¶

    개념: 자료형(Data Type)과 정적 타이핑¶

    비유로 시작 ☕

    카페에 가면 컵 크기가 정해져 있죠? 톨·그란데·벤티처럼요. C언어의 자료형도 똑같아요. "이 변수에는 정수만 담을 거야"라고 그릇의 종류와 크기를 미리 정해놓는 것입니다.

    파이썬에서는 x = 10이라고 쓰면 알아서 정수로 인식했어요. 하지만 C에서는 이렇게 써야 합니다:

    int x = 10;  // "정수(int) 전용 그릇 x를 만들고, 10을 넣어줘"

    왜 이렇게 엄격할까요? 🤔

    C언어는 메모리를 직접 관리하는 언어예요. 컴퓨터에게 "몇 바이트를 확보해야 하는지" 미리 알려줘야 효율적으로 동작합니다.

    기본 자료형 3가지:

    • int → 정수 (4바이트) → 예: int score = 0;
    • float → 소수점 있는 수 (4바이트) → 예: float avg = 3.14;
    • char → 문자 하나 (1바이트) → 예: char grade = 'A';

    💡 파이썬 = 동적 타이핑 (알아서 판단) / C = 정적 타이핑 (내가 미리 지정)

    🔨 따라하기¶

    Step 1: MBTI 점수 변수 선언하기¶

    MBTI 게임에서 E(외향)와 I(내향) 점수를 저장할 변수를 만들어봅시다!

    #include <stdio.h>

int main(void) {
    // MBTI 점수 변수 선언 및 초기화
    int score_E = 0;   // 외향(E) 점수
    int score_I = 0;   // 내향(I) 점수

    // 질문에 따라 점수 추가
    score_E = score_E + 3;
    score_I = score_I + 1;

    printf("E 점수: %d\n", score_E);
    printf("I 점수: %d\n", score_I);

    return 0;
}

    실행 결과: 

    E 점수: 3
I 점수: 1

    Step 2: 자료형을 잘못 쓰면? 😱¶

    int score = 3.7;  // 정수 그릇에 소수를 넣으면?
printf("점수: %d\n", score);

    실행 결과: 

    점수: 3

    소수점이 잘려나갑니다! int 그릇은 정수만 담을 수 있으니까요. 이런 실수를 방지하려면 자료형 선택이 중요합니다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int score_E = 0;
    int score_I = 0;

    score_E = score_E + 3;
    score_I = score_I + 1;

    printf("E 점수: %d\n", score_E);
    printf("I 점수: %d\n", score_I);

    // 자료형 실험
    int wrong = 3.7;
    printf("잘린 값: %d\n", wrong);

    return 0;
}

    ⚠️ 주의할 점¶

    • 🚫 변수 선언 없이 사용 불가: score = 10;이라고 바로 쓰면 에러! 반드시 int score = 10;처럼 자료형부터
    • 🚫 int에 소수를 넣으면 소수점 이하가 사라짐: 소수가 필요하면 float을 쓰세요

    ✅ 점검하기¶

    1. C에서 정수를 저장하려면 어떤 자료형을 사용하나요?

    정답 확인int를 사용합니다. 예: int num = 5;

    2. 파이썬과 달리 C에서 변수를 만들 때 반드시 해야 하는 것은?

    정답 확인자료형을 미리 선언해야 합니다. (정적 타이핑)

    3. int x = 9.8; 의 결과로 x에 저장되는 값은?

    정답 확인9 (소수점 이하가 잘려나갑니다)
