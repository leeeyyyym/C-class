    변수와 자료형 — 이름표를 붙이자¶

    🎯 이 장에서 배우는 것¶

    • C언어에서 변수를 선언할 때 자료형이 필요한 이유를 설명할 수 있다
    • int, float, char를 사용해 변수를 선언하고 값을 출력할 수 있다

    📚 핵심 개념¶

    개념: 자료형(Type) — 택배 상자의 라벨¶

    파이썬에서는 x = 10이면 끝이죠. 알아서 "아, 정수구나" 판단해 줍니다.

    C는 다릅니다. 택배 상자에 라벨을 먼저 붙여야 합니다 📦

    "이 상자에는 정수만 넣을 거야" → int x = 10;

    이걸 정적 타이핑이라고 해요. 왜 이렇게 할까요? C는 메모리를 직접 관리하기 때문에, 얼마만큼의 공간을 확보할지 미리 알아야 하거든요.

    graph LR A["파이썬 🐍<br>x = 10<br>(알아서 판단)"] --- VS["VS"] VS --- B["C언어 ⚙️<br>int x = 10;<br>(미리 선언)"] style A fill:#306998,color:#fff style B fill:#555,color:#fff style VS fill:#f90,color:#fff

    자주 쓰는 3가지 자료형:

    • int — 정수 (4바이트) → %d로 출력
    • float — 소수점 있는 수 (4바이트) → %f로 출력
    • char — 문자 하나 (1바이트) → %c로 출력

    🔨 따라하기¶

    Step 1: 변수 선언하고 출력하기¶

    #include <stdio.h>

int main(void) {
    int score = 85;          // 정수형 변수
    float height = 172.5;    // 실수형 변수
    char grade = 'A';        // 문자형 변수 (작은따옴표!)

    printf("점수: %d\n", score);
    printf("키: %.1f\n", height);
    printf("등급: %c\n", grade);

    return 0;
}

    실행 결과: 

    점수: 85
키: 172.5
등급: A

    Step 2: MBTI 게임용 변수 미리 만들기¶

    #include <stdio.h>

int main(void) {
    char initial = 'J';      // 플레이어 이니셜
    int mbti_score = 0;       // MBTI 점수 (나중에 누적!)

    printf("플레이어: %c\n", initial);
    printf("현재 점수: %d\n", mbti_score);

    return 0;
}

    실행 결과: 

    플레이어: J
현재 점수: 0

    ⚠️ 주의할 점¶

    1. char는 작은따옴표! 'A'는 문자, "A"는 문자열 — 전혀 다릅니다
    2. 서식 지정자를 틀리면 엉뚱한 값이 나와요. int에 %f를 쓰면 이상한 숫자가 출력됩니다

    ✅ 점검하기¶

    1. 파이썬과 달리 C에서 변수 선언 시 자료형을 적어야 하는 이유는?

    정답 확인C는 메모리 공간을 미리 확보해야 하므로, 어떤 종류의 데이터가 들어갈지 알려줘야 합니다 (정적 타이핑).

    2. float temp = 36.5;를 printf로 출력할 때 알맞은 서식 지정자는?

    정답 확인%f 입니다. 예: printf("%f", temp);

    3. char ch = "B";는 왜 틀렸을까요?

    정답 확인char는 작은따옴표를 써야 합니다. 올바른 코드: char ch = 'B';
