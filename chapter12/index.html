    구조체 — 플레이어 정보를 하나로 묶기¶

    🎯 이 장에서 배우는 것¶

    • struct 키워드로 구조체를 정의하고 변수를 선언할 수 있다
    • 점(.) 연산자로 멤버에 접근하여 값을 저장하고 읽을 수 있다
    • 플레이어 정보(이름, 점수, 결과)를 구조체 하나로 관리할 수 있다

    📚 핵심 개념¶

    개념: 구조체(struct)¶

    1. 비유로 시작 🎒

    학생증 한 장을 떠올려 보세요. 이름, 학번, 학과가 카드 한 장에 다 들어있죠? 구조체는 이것과 같습니다. 서로 다른 타입의 데이터를 하나의 이름 아래 묶어주는 기능이에요.

    구조체가 없다면 이런 상황이 벌어집니다:

    char name[20];      // 플레이어 이름
int scores[4];      // 4개 영역 점수
char result[5];     // MBTI 결과

    변수 3개가 따로 놀고 있어요. 플레이어가 2명이면? 6개, 10명이면 30개… 😵 관리가 불가능해집니다.

    2. 정확한 정의

    struct는 서로 다른 타입의 변수들을 하나의 새로운 타입으로 묶는 C 문법입니다.

    struct Player {
    char name[20];    // 멤버 1: 이름
    int scores[4];    // 멤버 2: 점수 배열
    char result[5];   // 멤버 3: MBTI 결과
};

    3. 예시로 확인

    graph LR A["struct Player"] --> B["name: 홍길동"] A --> C["scores: 3, 1, 2, 4"] A --> D["result: ENFP"]

    struct Player라는 설계도를 만들고, 이 설계도로 변수를 찍어내는 방식입니다.

    💡 파이썬과 비교: 파이썬 딕셔너리 {"name": "홍길동", "scores": [3,1,2,4]}와 비슷하지만, C 구조체는 멤버의 타입이 미리 정해져 있습니다.

    🔨 따라하기¶

    Step 1: 구조체 정의하고 값 넣기¶

    #include <stdio.h>
#include <string.h>

// 구조체 설계도 정의
struct Player {
    char name[20];
    int scores[4];
    char result[5];
};

int main(void) {
    // 설계도로 변수 생성
    struct Player p1;

    // 점(.) 연산자로 멤버에 접근
    strcpy(p1.name, "홍길동");
    p1.scores[0] = 3;
    p1.scores[1] = 1;
    p1.scores[2] = 2;
    p1.scores[3] = 4;
    strcpy(p1.result, "ENFP");

    printf("이름: %s\n", p1.name);
    printf("점수: %d %d %d %d\n",
        p1.scores[0], p1.scores[1],
        p1.scores[2], p1.scores[3]);
    printf("결과: %s\n", p1.result);

    return 0;
}

    실행 결과: 

    이름: 홍길동
점수: 3 1 2 4
결과: ENFP

    핵심은 점(.) 연산자입니다. p1.name은 "p1이라는 플레이어의 이름"이라는 뜻이에요. 직관적이죠? 😊

    Step 2: 기존 MBTI 게임에 적용하기¶

    흩어진 변수들을 구조체로 정리하면 코드가 훨씬 깔끔해집니다.

    #include <stdio.h>
#include <string.h>

struct Player {
    char name[20];
    int scores[4];   // E/I, S/N, T/F, J/P 점수
    char result[5];
};

int main(void) {
    struct Player player;

    // 이름 입력
    printf("플레이어 이름: ");
    scanf("%s", player.name);

    // 점수 초기화 & 간단 질문 1개
    for (int i = 0; i < 4; i++) {
        player.scores[i] = 0;
    }

    printf("혼자 시간 보내는 게 좋다? (0:아니오 1:예) ");
    scanf("%d", &player.scores[0]);  // E/I 점수

    // 결과 판정 (간략 버전)
    player.result[0] = (player.scores[0] >= 1) ? 'I' : 'E';
    player.result[1] = 'N';
    player.result[2] = 'F';
    player.result[3] = 'P';
    player.result[4] = '\0';

    printf("\n=== %s님의 결과: %s ===\n",
        player.name, player.result);

    return 0;
}

    실행 결과: 

    플레이어 이름: 철수
혼자 시간 보내는 게 좋다? (0:아니오 1:예) 1

=== 철수님의 결과: INFP ===

    변수가 player 하나로 깔끔하게 정리됐습니다! 🎉

    📝 전체 코드¶

    #include <stdio.h>
#include <string.h>

struct Player {
    char name[20];
    int scores[4];
    char result[5];
};

int main(void) {
    struct Player player;

    printf("플레이어 이름: ");
    scanf("%s", player.name);

    for (int i = 0; i < 4; i++) {
        player.scores[i] = 0;
    }

    printf("혼자 시간 보내는 게 좋다? (0:아니오 1:예) ");
    scanf("%d", &player.scores[0]);

    player.result[0] = (player.scores[0] >= 1) ? 'I' : 'E';
    player.result[1] = 'N';
    player.result[2] = 'F';
    player.result[3] = 'P';
    player.result[4] = '\0';

    printf("\n=== %s님의 결과: %s ===\n",
        player.name, player.result);

    return 0;
}

    ⚠️ 주의할 점¶

    • 구조체 정의 끝에 세미콜론(;) 필수! struct Player { ... }; ← 이 세미콜론을 빼먹으면 알 수 없는 에러가 쏟아집니다.
    • 문자열 멤버에는 =로 직접 대입 불가! p1.name = "홍길동" ❌ → strcpy(p1.name, "홍길동") ✅ (배열 챕터에서 배운 규칙 그대로!)

    ✅ 점검하기¶

    1. 구조체의 멤버에 접근할 때 사용하는 연산자는?

    정답 확인점(.) 연산자입니다. 예: player.name

    2. 아래 코드의 문제점은? 

    struct Player { char name[20]; int score; }

    정답 확인닫는 중괄호 뒤에 세미콜론(;)이 빠져 있습니다. };로 끝나야 합니다.

    3. 구조체를 사용하면 좋은 이유를 한 문장으로 설명해보세요.

    정답 확인관련된 여러 데이터를 하나의 변수로 묶어 관리할 수 있어 코드가 깔끔해지고, 플레이어가 여러 명일 때 확장이 쉽습니다.

    🔗 다음 장 미리보기¶

    구조체 하나로 플레이어 1명을 관리할 수 있게 됐어요. 그런데 플레이어가 여러 명이라면? 다음 장에서는 구조체 배열과 파일 입출력을 결합해서 여러 플레이어의 결과를 저장하고 불러오는 방법을 배웁니다! 💾
