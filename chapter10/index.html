    Chapter 10. MBTI 게임 최종 완성 — 전체 코드 통합과 회고¶

    🎯 이 장에서 배우는 것¶

    • 7차시에 걸쳐 작성한 코드를 하나의 완성된 프로그램으로 통합·실행할 수 있다
    • 프로그램의 전체 흐름(입력→처리→출력)을 구조적으로 설명할 수 있다
    • C언어에서 아두이노/ESP로 이어지는 학습 로드맵을 인식할 수 있다

    📚 핵심 개념¶

    개념: 코드 통합과 프로그램 흐름¶

    1. 비유로 시작: "코드 통합은 마치 퍼즐 조각을 맞추는 것과 같아요." 지금까지 변수, 조건문, 반복문, 배열, 함수, 구조체라는 조각을 하나씩 만들었고, 이제 그 조각들을 제자리에 끼워 완성된 그림을 봅니다. 🧩

    2. 정확한 정의: 프로그램 통합이란 개별적으로 작성·테스트한 코드 모듈들을 하나의 main 함수 안에서 올바른 순서로 연결하는 작업입니다. 핵심은 입력 → 처리 → 출력이라는 3단계 흐름입니다.

    3. 예시로 확인:

    flowchart LR A["🎤 입력\n이름 입력\n질문 응답"] --> B["⚙️ 처리\n점수 누적\n유형 판별"] B --> C["📊 출력\nMBTI 결과\n유형 설명"]

    우리 MBTI 게임도 정확히 이 흐름을 따릅니다!

    🔨 따라하기¶

    Step 1: 최종 코드 통합 — 복사해서 실행하기¶

    아래 전체 코드를 복사하여 컴파일·실행해 보세요. 각 주석에 몇 차시에서 배운 개념인지 표시해 두었습니다.

    Step 2: 실행하며 확인하기¶

    컴파일 후 실행하면 이름을 입력하고, 4개 질문에 답하면 MBTI 결과가 출력됩니다.

    실행 결과 예시: 

    ============================
   MBTI 성격유형 테스트
============================

이름을 입력하세요: 민수

[질문 1/4] 새로운 사람을 만나면 에너지가 생긴다? (1:YES / 0:NO): 1
[질문 2/4] 상상보다 현실적 사실을 중시한다? (1:YES / 0:NO): 0
[질문 3/4] 결정할 때 논리를 감정보다 우선한다? (1:YES / 0:NO): 1
[질문 4/4] 계획을 세우는 것을 선호한다? (1:YES / 0:NO): 0

============================
  민수님의 결과: ENTP
  탐험가형 - 뜨거운 논쟁을 즐기는 변론가!
============================

    📝 전체 코드¶

    #include <stdio.h>
#include <string.h>

/* ── 구조체 (Ch.8) ── */
typedef struct {
    char name[50];
    int scores[4];   /* E/S/T/J 점수 */
    char result[5];   /* MBTI 4글자 + '\0' */
} Player;

/* ── 질문 배열 (Ch.6~7) ── */
const char *questions[4] = {
    "새로운 사람을 만나면 에너지가 생긴다?",
    "상상보다 현실적 사실을 중시한다?",
    "결정할 때 논리를 감정보다 우선한다?",
    "계획을 세우는 것을 선호한다?"
};

/* ── 함수: 질문하기 (Ch.7) ── */
void askQuestions(Player *p) {
    int i, answer;
    for (i = 0; i < 4; i++) {              /* 반복문 (Ch.5) */
        printf("\n[질문 %d/4] %s (1:YES / 0:NO): ", i + 1, questions[i]);
        scanf("%d", &answer);
        if (answer == 1) {                  /* 조건문 (Ch.4) */
            p->scores[i] = 1;
        } else {
            p->scores[i] = 0;
        }
    }
}

/* ── 함수: 유형 판별 (Ch.7~8) ── */
void determineType(Player *p) {
    p->result[0] = (p->scores[0] == 1) ? 'E' : 'I';
    p->result[1] = (p->scores[1] == 1) ? 'S' : 'N';
    p->result[2] = (p->scores[2] == 1) ? 'T' : 'F';
    p->result[3] = (p->scores[3] == 1) ? 'J' : 'P';
    p->result[4] = '\0';
}

/* ── 함수: 결과 출력 (Ch.3~9) ── */
void printResult(Player *p) {
    printf("\n============================\n");
    printf("  %s님의 결과: %s\n", p->name, p->result);

    if (strcmp(p->result, "ENTP") == 0)
        printf("  탐험가형 - 뜨거운 논쟁을 즐기는 변론가!\n");
    else if (strcmp(p->result, "ISTJ") == 0)
        printf("  관리자형 - 책임감 강한 현실주의자!\n");
    else
        printf("  당신만의 독특한 유형입니다!\n");

    printf("============================\n");
}

/* ── 메인 (Ch.2~3) ── */
int main(void) {
    Player player;
    memset(&player, 0, sizeof(Player));

    printf("============================\n");
    printf("   MBTI 성격유형 테스트\n");
    printf("============================\n");

    printf("\n이름을 입력하세요: ");
    scanf("%49s", player.name);             /* 변수·입력 (Ch.2~3) */

    askQuestions(&player);
    determineType(&player);
    printResult(&player);

    return 0;
}

    ⚠️ 주의할 점¶

    • scanf("%49s", ...) — 버퍼 크기(50)보다 1 작은 49를 써서 오버플로를 방지합니다. 이름에 공백이 포함되면 fgets로 교체하세요.
    • 질문 수 확장 시 — 질문을 늘리면 scores 배열 크기와 for 반복 횟수, determineType 로직을 함께 수정해야 합니다.

    ✅ 점검하기¶

    1. 이 프로그램의 3단계 흐름을 순서대로 말해 보세요.

    정답 확인 **입력**(이름·질문 응답) → **처리**(점수 누적·유형 판별) → **출력**(MBTI 결과 출력)

    2. determineType 함수에서 p->scores[0]이 0이면 result[0]에 어떤 글자가 들어가나요?

    정답 확인 `'I'`가 들어갑니다. 삼항 연산자에서 조건이 거짓(0)이므로 `:` 뒤의 값이 선택됩니다.

    3. 이 프로그램에서 구조체를 사용한 이유를 한 문장으로 설명해 보세요.

    정답 확인 이름, 점수 배열, 결과 문자열처럼 한 플레이어에 속하는 여러 데이터를 하나로 묶어 함수 간에 깔끔하게 전달하기 위해서입니다.
