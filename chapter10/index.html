    배열 (2) — MBTI 결과를 판정하자¶

    🎯 이 장에서 배우는 것¶

    • 배열의 점수를 비교하여 각 차원의 결과 문자를 결정할 수 있다
    • char 배열에 결과를 모아 MBTI 유형 문자열을 완성할 수 있다
    • 질문 → 점수 집계 → 결과 출력까지 전체 흐름을 이해할 수 있다

    📚 핵심 개념¶

    개념: 점수 비교로 결과 문자 결정하기¶

    비유로 시작 🗳️

    선거 개표를 떠올려 보세요. 두 후보의 득표수를 비교해서 더 많은 쪽이 당선되죠? MBTI 판정도 똑같아요. 각 차원에서 두 성향의 점수를 비교하고, 높은 쪽의 글자를 결과로 뽑는 겁니다.

    정확한 정의

    MBTI는 4개 차원으로 이루어져 있고, 각 차원마다 두 성향이 경쟁합니다.

    • 차원 0: E vs I
    • 차원 1: S vs N
    • 차원 2: T vs F
    • 차원 3: J vs P

    지난 챕터에서 scores[0]~scores[3]에 점수를 저장했어요. 여기서는 양수/음수 방식 대신, 두 개의 배열로 각 성향의 점수를 따로 관리하는 방식을 사용합니다.

    예시로 확인

    E 점수가 3, I 점수가 1이라면? → E가 이기니까 결과는 'E'!

    if (scoreA[0] >= scoreB[0])
    result[0] = 'E';
else
    result[0] = 'I';

    이런 비교를 4번 반복하면 result 배열에 E, N, F, P 같은 글자가 하나씩 채워집니다. 마지막에 널 문자 '\0'을 넣으면 완전한 문자열이 되죠!

    🔨 따라하기¶

    Step 1: 점수 비교 → 결과 문자 채우기¶

    핵심 로직만 먼저 이해해 봅시다.

    // 각 차원의 두 성향 글자
char optionA[4] = {'E', 'S', 'T', 'J'};
char optionB[4] = {'I', 'N', 'F', 'P'};

// 가상의 점수 (질문에서 집계되었다고 가정)
int scoreA[4] = {3, 1, 2, 0};  // E, S, T, J 점수
int scoreB[4] = {1, 3, 2, 4};  // I, N, F, P 점수

// 결과를 담을 char 배열 (4글자 + 널문자)
char result[5];

for (int i = 0; i < 4; i++) {
    if (scoreA[i] >= scoreB[i])
        result[i] = optionA[i];
    else
        result[i] = optionB[i];
}
result[4] = '\0';  // 문자열 끝 표시!

    실행하면 result에는: "ENTP" 가 들어갑니다.

    💡 '\0'(널 문자)는 C에서 "여기가 문자열의 끝"이라는 신호예요. 이걸 빼먹으면 printf가 엉뚱한 데까지 출력할 수 있어요!

    Step 2: 전체 MBTI 게임 완성하기¶

    이제 질문 → 입력 → 집계 → 판정 → 출력까지 한 번에 돌아가는 코드를 만들어 봅시다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    // 질문 8개 (각 차원당 2문제)
    char *questions[8] = {
        "모임에서 에너지를 얻는다 (1) vs 혼자서 충전한다 (2)",
        "사람이 많으면 신난다 (1) vs 소수가 편하다 (2)",
        "현실적인 편이다 (1) vs 상상력이 풍부하다 (2)",
        "구체적인 게 좋다 (1) vs 가능성이 좋다 (2)",
        "논리로 판단한다 (1) vs 감정으로 판단한다 (2)",
        "공정함이 중요하다 (1) vs 배려가 중요하다 (2)",
        "계획적으로 산다 (1) vs 즉흥적으로 산다 (2)",
        "미리 정하는 게 좋다 (1) vs 열어두는 게 좋다 (2)"
    };

    // 각 질문이 어떤 차원인지 (0:EI, 1:SN, 2:TF, 3:JP)
    int dimension[8] = {0, 0, 1, 1, 2, 2, 3, 3};

    char optionA[4] = {'E', 'S', 'T', 'J'};
    char optionB[4] = {'I', 'N', 'F', 'P'};
    int scoreA[4] = {0, 0, 0, 0};
    int scoreB[4] = {0, 0, 0, 0};

    // 질문하고 점수 집계
    printf("=== MBTI 테스트 ===\n\n");
    for (int i = 0; i < 8; i++) {
        int answer;
        printf("Q%d. %s\n", i + 1, questions[i]);
        printf("입력 (1 또는 2): ");
        scanf("%d", &answer);

        int d = dimension[i];  // 이 질문의 차원 번호
        if (answer == 1)
            scoreA[d]++;
        else
            scoreB[d]++;
        printf("\n");
    }

    // 결과 판정
    char result[5];
    for (int i = 0; i < 4; i++) {
        if (scoreA[i] >= scoreB[i])
            result[i] = optionA[i];
        else
            result[i] = optionB[i];
    }
    result[4] = '\0';

    // 결과 출력
    printf("🎉 당신의 MBTI는: %s\n", result);

    return 0;
}

    실행 결과 예시: 

    === MBTI 테스트 ===

Q1. 모임에서 에너지를 얻는다 (1) vs 혼자서 충전한다 (2)
입력 (1 또는 2): 1

Q2. 사람이 많으면 신난다 (1) vs 소수가 편하다 (2)
입력 (1 또는 2): 2

... (중략) ...

🎉 당신의 MBTI는: ENFP

    ⚠️ 주의할 점¶

    • result[4] = '\0';을 절대 빼먹지 마세요! 이것 없이 printf("%s", result)를 하면 쓰레기 값까지 출력됩니다. C에서 문자 배열을 문자열처럼 쓰려면 반드시 끝에 널 문자가 필요해요.
    • 배열 크기를 4가 아닌 5로 선언하는 이유도 같습니다. 글자 4개 + 널 문자 1개 = 5칸이 필요하죠.

    ✅ 점검하기¶

    1. char result[5]에서 크기가 4가 아닌 5인 이유는?

    정답 확인MBTI 결과 4글자(예: ENFP) + 문자열 끝을 표시하는 널 문자('\0') 1개 = 총 5칸이 필요하기 때문입니다.

    2. 어떤 차원에서 두 성향의 점수가 동점이면 어떻게 되나요? (코드를 보고 답해보세요)

    정답 확인if 조건이 `scoreA[i] >= scoreB[i]`이므로, 동점일 때는 optionA 쪽(E, S, T, J)이 선택됩니다. >=가 아닌 >로 바꾸면 동점 시 반대 성향이 선택되겠죠!

    3. dimension[8] 배열의 역할은 무엇인가요?

    정답 확인각 질문이 MBTI의 어떤 차원(0:EI, 1:SN, 2:TF, 3:JP)에 해당하는지 알려주는 매핑 배열입니다. 질문 번호로 차원 번호를 찾아 해당 점수를 올릴 수 있게 해줍니다.
