    배열 — 질문 목록을 한곳에 저장하기¶

    🎯 이 장에서 배우는 것¶

    • C언어에서 1차원 배열을 선언하고 인덱스로 요소에 접근할 수 있다
    • 파이썬 리스트와 C 배열의 차이(고정 크기, 동일 타입)를 설명할 수 있다
    • MBTI 질문을 문자열 배열에 저장하고 for문으로 출력할 수 있다

    📚 핵심 개념¶

    개념: 배열(Array)¶

    1. 비유로 시작 🗄️

    배열은 마치 번호가 붙은 사물함과 같아요. 사물함 4개가 일렬로 있으면 0번, 1번, 2번, 3번으로 부르죠. 각 칸에는 같은 종류의 물건만 넣을 수 있고, 칸 수는 처음에 정해지면 바꿀 수 없어요.

    2. 정확한 정의

    배열은 같은 타입의 데이터를 연속된 메모리에 저장하는 자료구조입니다. 선언할 때 타입과 크기를 고정합니다.

    int scores[4];          // int형 4칸짜리 배열
char* questions[4];     // 문자열 포인터 4칸짜리 배열

    3. 파이썬과 비교

    flowchart LR subgraph Python["🐍 파이썬 리스트"] P1["크기 자유롭게 변경"] P2["다른 타입 섞기 가능"] end subgraph C["⚙️ C 배열"] C1["크기 선언 시 고정"] C2["같은 타입만 저장"] end

    💡 인덱스는 0부터 시작! scores[4]를 선언하면 scores[0] ~ scores[3]까지 사용합니다. scores[4]에 접근하면 오류!

    🔨 따라하기¶

    Step 1: 배열에 질문 저장하고 출력하기¶

    지금까지 printf에 질문을 직접 적었죠? 이제 배열에 모아서 for문으로 한번에 출력합니다.

    코드:

    #include <stdio.h>

int main(void) {
    // 질문 4개를 배열에 저장
    char* questions[4] = {
        "혼자보다 여럿이 있을 때 에너지가 충전된다",  // 0번: E/I
        "구체적인 사실이 상상보다 중요하다",          // 1번: S/N
        "결정할 때 논리가 감정보다 우선이다",          // 2번: T/F
        "계획을 세우고 실행하는 편이다"               // 3번: J/P
    };

    // 각 축의 점수를 저장할 배열 (0으로 초기화)
    int scores[4] = {0, 0, 0, 0};

    // for문으로 전체 질문 출력 + 입력 받기
    for (int i = 0; i < 4; i++) {
        printf("Q%d. %s\n", i + 1, questions[i]);
        printf("(1:매우아니다 ~ 5:매우그렇다): ");
        scanf("%d", &scores[i]);
    }

    // 결과 확인
    printf("\n--- 입력된 점수 ---\n");
    for (int i = 0; i < 4; i++) {
        printf("Q%d 점수: %d\n", i + 1, scores[i]);
    }

    return 0;
}

    실행 결과:

    Q1. 혼자보다 여럿이 있을 때 에너지가 충전된다
(1:매우아니다 ~ 5:매우그렇다): 4
Q2. 구체적인 사실이 상상보다 중요하다
(1:매우아니다 ~ 5:매우그렇다): 2
Q3. 결정할 때 논리가 감정보다 우선이다
(1:매우아니다 ~ 5:매우그렇다): 5
Q4. 계획을 세우고 실행하는 편이다
(1:매우아니다 ~ 5:매우그렇다): 3

--- 입력된 점수 ---
Q1 점수: 4
Q2 점수: 2
Q3 점수: 5
Q4 점수: 3

    핵심을 보세요 — questions[i]와 scores[i]에서 i 하나만 바꾸면 모든 질문과 점수에 접근합니다. 질문이 20개로 늘어나도 for문의 4만 20으로 바꾸면 됩니다! 🎉

    📝 전체 코드¶

    위 Step 1의 코드가 이 장의 전체 코드입니다. 복사해서 바로 실행해 보세요!

    ⚠️ 주의할 점¶

    • 인덱스 범위 초과 금지: int scores[4]에서 scores[4]를 쓰면 존재하지 않는 칸에 접근하는 것입니다. C는 이걸 알아서 막아주지 않아요 — 프로그램이 이상하게 동작하거나 죽을 수 있습니다.
    • 배열 크기는 변경 불가: 파이썬처럼 append()로 늘릴 수 없습니다. 처음부터 넉넉하게 선언하세요.

    ✅ 점검하기¶

    1. int data[3] = {10, 20, 30};에서 data[1]의 값은?

    정답 확인20입니다. 인덱스는 0부터 시작하므로 data[0]=10, data[1]=20, data[2]=30입니다.

    2. C 배열이 파이썬 리스트와 다른 점 2가지는?

    정답 확인①크기가 선언 시 고정된다 ②같은 타입의 데이터만 저장할 수 있다

    3. int arr[5];에서 사용 가능한 인덱스 범위는?

    정답 확인arr[0]부터 arr[4]까지입니다. arr[5]는 범위를 벗어나므로 사용하면 안 됩니다.
