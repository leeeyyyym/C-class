    반복문으로 질문 돌리기 — for와 while¶

    🎯 이 장에서 배우는 것¶

    • for문과 while문의 문법 차이를 이해하고 적절히 사용할 수 있다
    • 반복문으로 여러 개의 MBTI 질문을 순서대로 출력할 수 있다
    • 반복문 안에서 점수를 누적하는 구조를 만들 수 있다

    📚 핵심 개념¶

    개념: 반복문¶

    비유로 시작 🎡

    반복문은 마치 놀이공원 회전목마와 같아요. "3바퀴 돌아!" 하면 정확히 3바퀴를 돌고, "어지러울 때까지 돌아!" 하면 조건이 충족될 때까지 계속 돕니다.

    정확한 정의

    • for문: 반복 횟수가 정해져 있을 때 사용합니다. "4개 질문을 순서대로" 같은 상황이죠.
    • while문: 반복 횟수가 조건에 따라 달라질 때 사용합니다. "유효한 답이 올 때까지" 같은 상황이에요.

    예시로 확인

    # for문: 0, 1, 2, 3 — 정확히 4번 반복
for i in range(4):
    print(f"{i}번째 질문!")

# while문: 조건이 참인 동안 반복
count = 0
while count < 4:
    print(f"{count}번째 질문!")
    count += 1  # 이걸 빼면 무한루프! 😱
    flowchart LR A["for문"] -->|"횟수가 정해짐"| B["range(4) → 4번 반복"] C["while문"] -->|"조건으로 판단"| D["조건이 거짓이면 멈춤"]

    🔨 따라하기¶

    Step 1: for문으로 4개 질문 출력하기¶

    MBTI의 4가지 축(E/I, S/N, T/F, J/P)에 해당하는 질문을 리스트에 담고, for문으로 하나씩 꺼내봅시다.

    코드:

    # MBTI 질문 리스트
questions = [
    "모임에서 에너지를 얻나요? (1:예 2:아니오)",
    "구체적인 사실을 선호하나요? (1:예 2:아니오)",
    "결정할 때 논리를 우선하나요? (1:예 2:아니오)",
    "계획적으로 행동하나요? (1:예 2:아니오)"
]

# for문으로 질문 순서대로 출력
for i in range(4):
    print(f"Q{i+1}. {questions[i]}")

    실행 결과:

    Q1. 모임에서 에너지를 얻나요? (1:예 2:아니오)
Q2. 구체적인 사실을 선호하나요? (1:예 2:아니오)
Q3. 결정할 때 논리를 우선하나요? (1:예 2:아니오)
Q4. 계획적으로 행동하나요? (1:예 2:아니오)

    i가 0→1→2→3으로 바뀌면서 질문이 순서대로 나옵니다! 🎉

    Step 2: 답변 받고 점수 누적하기¶

    이제 각 질문에 답변을 받아서 MBTI 결과를 만들어봅시다.

    코드:

    questions = [
    "모임에서 에너지를 얻나요? (1:예 2:아니오)",
    "구체적인 사실을 선호하나요? (1:예 2:아니오)",
    "결정할 때 논리를 우선하나요? (1:예 2:아니오)",
    "계획적으로 행동하나요? (1:예 2:아니오)"
]

# 각 질문의 "예"에 해당하는 유형
yes_types = ["E", "S", "T", "J"]
no_types  = ["I", "N", "F", "P"]

result = ""  # 결과 문자열 누적

for i in range(4):
    print(f"\nQ{i+1}. {questions[i]}")
    answer = input("답변: ")

    # while문으로 유효한 입력이 올 때까지 반복
    while answer not in ["1", "2"]:
        print("⚠️ 1 또는 2만 입력해주세요!")
        answer = input("답변: ")

    if answer == "1":
        result += yes_types[i]
    else:
        result += no_types[i]

print(f"\n🎉 당신의 MBTI는: {result}")

    실행 결과 (예시):

    Q1. 모임에서 에너지를 얻나요? (1:예 2:아니오)
답변: 1

Q2. 구체적인 사실을 선호하나요? (1:예 2:아니오)
답변: 2

Q3. 결정할 때 논리를 우선하나요? (1:예 2:아니오)
답변: 1

Q4. 계획적으로 행동하나요? (1:예 2:아니오)
답변: 2

🎉 당신의 MBTI는: ENTP

    💡 포인트: for문이 질문을 돌리고, while문이 잘못된 입력을 걸러내는 역할을 합니다. 두 반복문이 자연스럽게 협력하고 있어요!

    📝 전체 코드¶

    questions = [
    "모임에서 에너지를 얻나요? (1:예 2:아니오)",
    "구체적인 사실을 선호하나요? (1:예 2:아니오)",
    "결정할 때 논리를 우선하나요? (1:예 2:아니오)",
    "계획적으로 행동하나요? (1:예 2:아니오)"
]
yes_types = ["E", "S", "T", "J"]
no_types  = ["I", "N", "F", "P"]

result = ""

for i in range(4):
    print(f"\nQ{i+1}. {questions[i]}")
    answer = input("답변: ")
    while answer not in ["1", "2"]:
        print("⚠️ 1 또는 2만 입력해주세요!")
        answer = input("답변: ")
    if answer == "1":
        result += yes_types[i]
    else:
        result += no_types[i]

print(f"\n🎉 당신의 MBTI는: {result}")

    ⚠️ 주의할 점¶

    • while문에서 카운터 변수 업데이트를 빼먹으면 무한루프에 빠집니다. 프로그램이 멈추지 않으면 Ctrl+C로 강제 종료하세요!
    • range(4)는 0부터 3까지입니다. 1부터 4가 아니에요! 출력할 때 i+1로 보정하는 습관을 들이세요.

    ✅ 점검하기¶

    1. for i in range(3)은 몇 번 반복하고, i의 값은 어떻게 변하나요?

    정답 확인3번 반복하며, i는 0 → 1 → 2로 변합니다.

    2. while문과 for문 중, "사용자가 올바른 값을 입력할 때까지 반복"에 적합한 것은?

    정답 확인while문입니다. 몇 번 반복할지 미리 알 수 없고, 조건(올바른 입력)이 충족되면 멈춰야 하기 때문입니다.

    3. 아래 코드의 문제점은 무엇일까요? 

    count = 0
while count < 5:
    print(count)

    정답 확인count 값이 증가하지 않아 무한루프에 빠집니다. 반복문 안에 count += 1을 추가해야 합니다.
