    if-else — 선택에 따라 달라지는 반응¶

    Part 2: 게임에 두뇌를 달자 — 조건문과 반복문

    🎯 이 장에서 배우는 것¶

    • C언어의 if, else if, else 문법을 정확하게 작성할 수 있다
    • 파이썬과 C의 조건문 차이(들여쓰기 vs 중괄호)를 설명할 수 있다
    • 사용자 입력에 따라 다른 점수를 부여하는 코드를 작성할 수 있다

    📚 핵심 개념¶

    개념: if-else (조건문)¶

    1. 비유로 시작 🚦

    if-else는 마치 갈림길의 표지판과 같아요. "비가 오면 우산을 쓰고, 아니면 그냥 나간다" — 우리가 매일 하는 이런 판단을 코드로 옮긴 것입니다.

    2. 정확한 정의

    조건이 참(true) 이면 if 블록을, 거짓(false) 이면 else 블록을 실행합니다. 조건이 여러 개면 else if를 사이에 넣습니다.

    3. 파이썬 vs C 비교

    파이썬에서 이미 조건문을 써봤다면, C와의 차이만 잡으면 됩니다!

    flowchart LR A["파이썬 🐍"] --- B["elif 키워드"] A --- C["들여쓰기로 블록 구분"] A --- D["조건에 괄호 선택"] E["C언어 ⚙️"] --- F["else if 키워드"] E --- G["중괄호 {}로 블록 구분"] E --- H["조건에 괄호 필수"]

    핵심 차이 세 줄 요약: - 파이썬 elif → C에서는 else if (띄어쓰기!) - 파이썬은 들여쓰기 → C에서는 중괄호 {} - C에서는 조건을 반드시 소괄호 () 로 감쌈

    🔨 따라하기¶

    Step 1: MBTI 질문 하나 만들기¶

    MBTI 첫 질문을 출력하고, 사용자가 A 또는 B를 입력하면 E 점수 또는 I 점수를 올려봅시다.

    #include <stdio.h>

int main(void) {
    char answer;        // 사용자 입력을 담을 변수
    int e_score = 0;    // 외향(E) 점수
    int i_score = 0;    // 내향(I) 점수

    printf("Q. 주말에 나는?\n");
    printf("A: 친구들과 밖에서 논다\n");
    printf("B: 집에서 혼자 쉰다\n");
    printf("선택(A/B): ");
    scanf(" %c", &answer);   // 공백+%c → 엔터 무시 팁!

    if (answer == 'A') {
        e_score = e_score + 1;
        printf("에너지 충전! E +1\n");
    } else if (answer == 'B') {
        i_score = i_score + 1;
        printf("충분한 휴식! I +1\n");
    } else {
        printf("A 또는 B만 입력해주세요!\n");
    }

    printf("결과 → E:%d / I:%d\n", e_score, i_score);
    return 0;
}

    Step 2: 실행해보기¶

    A를 입력한 경우: 

    Q. 주말에 나는?
A: 친구들과 밖에서 논다
B: 집에서 혼자 쉰다
선택(A/B): A
에너지 충전! E +1
결과 → E:1 / I:0

    B를 입력한 경우: 

    선택(A/B): B
충분한 휴식! I +1
결과 → E:0 / I:1

    else 덕분에 A도 B도 아닌 입력에 안내 메시지가 나옵니다. 이것이 예외 처리의 시작이에요! 🛡️

    📝 전체 코드¶

    위 Step 1의 코드가 곧 전체 코드입니다. 복사해서 바로 실행해보세요!

    ⚠️ 주의할 점¶

    • scanf(" %c", ...)에서 %c 앞 공백을 빼먹지 마세요! 공백이 없으면 이전 엔터키가 입력으로 들어와 프로그램이 이상하게 동작합니다.
    • 문자 비교는 작은따옴표! 'A'는 문자, "A"는 문자열 — %c로 받았으면 반드시 'A'로 비교하세요.

    ✅ 점검하기¶

    1. 파이썬의 elif는 C에서 어떻게 쓸까요?

    정답 확인 `else if` (띄어쓰기 있음)

    2. C에서 if 조건문의 블록을 구분하는 기호는?

    정답 확인 중괄호 `{ }` (파이썬은 들여쓰기)

    3. answer == "A" 라고 쓰면 왜 안 될까요?

    정답 확인 `"A"`는 문자열이고, `char` 변수와 비교하려면 문자 리터럴 `'A'`(작은따옴표)를 써야 합니다.
