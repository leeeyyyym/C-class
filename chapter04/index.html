    조건문 — 네 선택에 따라 결과가 달라진다¶

    🎯 이 장에서 배우는 것¶

    • if, else if, else 문을 C언어 문법에 맞게 작성할 수 있다
    • 비교 연산자(==, !=, <, >)를 조건식에 활용할 수 있다
    • MBTI 질문의 답변에 따라 점수를 다르게 누적하는 코드를 작성할 수 있다

    📚 핵심 개념¶

    개념: 조건문 (if / else if / else)¶

    비유로 시작 🪧

    조건문은 갈림길 표지판과 같아요. "왼쪽으로 가면 바다, 오른쪽으로 가면 산"처럼, 조건이 참이면 이쪽 코드를, 거짓이면 저쪽 코드를 실행합니다.

    정확한 정의

    조건식의 결과(참/거짓)에 따라 실행할 코드 블록을 선택하는 제어문입니다.

    파이썬 vs C 비교

    flowchart LR A["🐍 파이썬"] --> B["if 조건:<br/> 코드<br/>elif 조건:<br/> 코드<br/>else:<br/> 코드"] C["⚙️ C언어"] --> D["if(조건) {<br/> 코드;<br/>} else if(조건) {<br/> 코드;<br/>} else {<br/> 코드;<br/>}"]

    핵심 차이 두 가지만 기억하세요!

    • 소괄호 필수: 조건을 ( ) 안에 넣는다
    • 중괄호 필수: 실행할 코드를 { } 로 감싼다

    자주 쓰는 비교 연산자

    • == 같다 / != 다르다
    • < 작다 / > 크다
    • <= 작거나 같다 / >= 크거나 같다

    🔨 따라하기¶

    Step 1: 간단한 조건문 체험¶

    먼저 조건문의 기본 흐름을 눈으로 확인해봅시다.

    #include <stdio.h>

int main(void) {
    int answer = 1;

    if(answer == 1) {
        printf("1번을 선택했습니다!\n");
    } else {
        printf("2번을 선택했습니다!\n");
    }

    return 0;
}

    실행 결과: 

    1번을 선택했습니다!

    answer 값을 2로 바꿔서도 실행해보세요! 😊

    Step 2: MBTI 질문 — 답변에 따라 점수 누적하기¶

    이제 진짜 MBTI 게임의 한 조각을 만들어봅시다! 사용자 입력을 받아 E점수 또는 I점수를 올립니다.

    #include <stdio.h>

int main(void) {
    int answer;
    int score_E = 0; // 외향 점수
    int score_I = 0; // 내향 점수

    printf("=== MBTI 테스트 ===\n");
    printf("파티에 가면?\n");
    printf("1: 새로운 사람과 대화한다\n");
    printf("2: 아는 사람과만 대화한다\n");
    printf("선택: ");
    scanf("%d", &answer);

    if(answer == 1) {
        score_E = score_E + 1;   // E 점수 +1
        printf("외향(E) 점수: %d\n", score_E);
    } else if(answer == 2) {
        score_I = score_I + 1;   // I 점수 +1
        printf("내향(I) 점수: %d\n", score_I);
    } else {
        printf("1 또는 2만 입력해주세요!\n");
    }

    return 0;
}

    실행 결과 (1 입력 시): 

    === MBTI 테스트 ===
파티에 가면?
1: 새로운 사람과 대화한다
2: 아는 사람과만 대화한다
선택: 1
외향(E) 점수: 1

    💡 else if가 핵심! 1도 2도 아닌 잘못된 입력은 else가 잡아줍니다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int answer;
    int score_E = 0;
    int score_I = 0;

    printf("=== MBTI 테스트 ===\n");
    printf("파티에 가면?\n");
    printf("1: 새로운 사람과 대화한다\n");
    printf("2: 아는 사람과만 대화한다\n");
    printf("선택: ");
    scanf("%d", &answer);

    if(answer == 1) {
        score_E = score_E + 1;
        printf("외향(E) 점수: %d\n", score_E);
    } else if(answer == 2) {
        score_I = score_I + 1;
        printf("내향(I) 점수: %d\n", score_I);
    } else {
        printf("1 또는 2만 입력해주세요!\n");
    }

    return 0;
}

    ⚠️ 주의할 점¶

    • =와 ==을 헷갈리지 마세요! =는 대입, ==는 비교입니다. if(answer = 1)이라고 쓰면 항상 참이 되어버려요! 🚨
    • 중괄호 { }를 빠뜨리지 마세요. 한 줄이라도 습관적으로 중괄호를 써야 나중에 코드를 추가할 때 실수를 막을 수 있습니다.

    ✅ 점검하기¶

    1. C언어 조건문에서 파이썬의 elif에 해당하는 키워드는?

    정답 확인 `else if` — C에서는 붙여 쓰지 않고 두 단어로 씁니다.

    2. if(score == 10) 에서 ==를 =로 바꾸면 어떤 일이 벌어질까요?

    정답 확인 `score`에 10이 대입되고, 대입 결과(10)가 0이 아니므로 조건이 항상 참이 됩니다. 비교가 아니라 대입이 되어버리는 대표적인 실수!

    3. 사용자가 1도 2도 아닌 값을 입력했을 때 이를 처리하려면 어떤 키워드를 쓰나요?

    정답 확인 `else` — 앞의 모든 조건이 거짓일 때 실행되는 마지막 갈림길입니다.
