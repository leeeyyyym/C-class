    비트연산자 맛보기 — 0과 1로 말하는 컴퓨터¶

    🎯 이 장에서 배우는 것¶

    • 비트(bit)와 2진수 표현 방식을 간단히 설명할 수 있다
    • AND(&), OR(|), 시프트(<<) 비트연산자의 동작을 체험할 수 있다
    • 비트연산이 실제로 어디에 쓰이는지 인지할 수 있다

    📚 핵심 개념¶

    개념: 비트연산자¶

    비유로 시작 💡

    "비트연산은 마치 전등 스위치 8개가 달린 패널과 같아요."

    각 스위치는 켜짐(1) 또는 꺼짐(0)만 있습니다. 비트연산자는 이 스위치들을 한꺼번에 조작하는 리모컨입니다.

    정확한 정의

    컴퓨터는 모든 데이터를 0과 1(비트)로 저장합니다. 비트연산자는 이 0과 1을 자리별로 직접 조작하는 연산자입니다.

    핵심 연산자 3가지

    • & (AND) — 둘 다 1일 때만 1 → 특정 비트 확인용
    • | (OR) — 둘 중 하나라도 1이면 1 → 특정 비트 켜기용
    • << (왼쪽 시프트) — 비트를 왼쪽으로 밀기 → 값이 2배씩 커짐
    graph LR A["1010 & 1100"] --> B["1000"] C["1010 | 1100"] --> D["1110"] E["0001 << 2"] --> F["0100"]

    🔨 따라하기¶

    Step 1: 비트연산 직접 체험하기¶

    # 🔢 숫자를 2진수로 보면서 비트연산 이해하기
a = 0b1010  # 10진수로 10
b = 0b1100  # 10진수로 12

print(f"a     = {a:04b} ({a})")
print(f"b     = {b:04b} ({b})")
print(f"a & b = {a & b:04b} ({a & b})")   # AND
print(f"a | b = {a | b:04b} ({a | b})")   # OR
print(f"1 << 3 = {1 << 3:04b} ({1 << 3})")  # 시프트

    실행 결과: 

    a     = 1010 (10)
b     = 1100 (12)
a & b = 1000 (8)
a | b = 1110 (14)
1 << 3 = 1000 (8)

    Step 2: LED 8개 제어 시뮬레이션¶

    # 💡 8개 LED를 비트로 제어하는 느낌 체험
leds = 0b00000000  # 모든 LED 꺼짐

leds = leds | (1 << 0)  # 0번 LED 켜기
print(f"0번 ON : {leds:08b}")

leds = leds | (1 << 4)  # 4번 LED 켜기
print(f"4번 ON : {leds:08b}")

# 0번 LED가 켜져 있는지 확인
if leds & (1 << 0):
    print("0번 LED는 켜져 있습니다! ✅")

    실행 결과: 

    0번 ON : 00010001
4번 ON : 00010001
0번 LED는 켜져 있습니다! ✅

    🤖 왜 배울까? 아두이노에서 LED, 모터, 센서를 제어할 때 이런 비트연산이 실제로 사용됩니다!

    📝 전체 코드¶

    # === 비트연산자 맛보기 ===
a = 0b1010
b = 0b1100

print(f"a     = {a:04b} ({a})")
print(f"b     = {b:04b} ({b})")
print(f"a & b = {a & b:04b} ({a & b})")
print(f"a | b = {a | b:04b} ({a | b})")
print(f"1 << 3 = {1 << 3:04b} ({1 << 3})")

print("\n--- LED 제어 시뮬레이션 ---")
leds = 0b00000000
leds = leds | (1 << 0)
print(f"0번 ON : {leds:08b}")
leds = leds | (1 << 4)
print(f"4번 ON : {leds:08b}")
if leds & (1 << 0):
    print("0번 LED는 켜져 있습니다! ✅")

    ⚠️ 주의할 점¶

    • &와 and는 다릅니다! &는 비트 단위, and는 논리(True/False) 연산입니다
    • 비트연산은 정수에만 사용하세요. 실수(float)에는 쓸 수 없습니다

    ✅ 점검하기¶

    1. 0b1010 & 0b1111의 결과는?

    정답 확인0b1010 (10) — AND에서 한쪽이 모두 1이면 다른 쪽 값이 그대로 나옵니다

    2. 3번 LED만 켜려면 1 << ?에서 ?에 뭘 넣어야 할까요?

    정답 확인3 — `1 << 3`은 0b00001000으로 3번 위치 비트가 1이 됩니다

    3. | 연산자는 비트를 켜나요, 확인하나요?

    정답 확인켜기(OR)입니다. 확인은 `&`(AND)를 사용합니다
