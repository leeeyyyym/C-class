    입출력 마스터 — 플레이어 이름을 입력받자¶

    🎯 이 장에서 배우는 것¶

    • scanf와 서식 지정자(%s, %d)를 사용해 사용자 입력을 받을 수 있다
    • printf와 scanf를 조합해 플레이어 이름 입력 화면을 완성할 수 있다

    📚 핵심 개념¶

    개념: scanf와 서식 지정자¶

    비유로 시작 ☕

    카페 주문서를 떠올려 보세요. 빈칸마다 "이름: ____", "수량: ____" 처럼 어떤 종류의 정보를 쓸지 미리 정해져 있죠? C의 scanf도 똑같아요. "여기엔 문자열이 올 거야(%s)", "여기엔 정수가 올 거야(%d)"라고 빈칸의 형식을 먼저 알려줘야 합니다.

    정확한 정의

    • scanf("서식", &변수) — 키보드에서 입력을 받아 변수에 저장하는 함수
    • 서식 지정자: %d(정수), %s(문자열), %c(문자 하나), %f(실수)

    💡 & 기호는 "이 변수의 주소"라는 뜻이에요. 지금은 정수·문자 입력 시 & 붙이기, 문자열(char 배열)은 & 안 붙이기만 기억하면 OK! 이유는 7차시(포인터)에서 다룹니다.

    🔨 따라하기¶

    Step 1: 이름 입력받기¶

    #include <stdio.h>

int main(void) {
    char name[20]; // 이름을 담을 그릇 (최대 19글자)

    printf("플레이어 이름을 입력하세요: ");
    scanf("%s", name); // 문자열이라 & 안 붙임!

    printf("%s님, MBTI 테스트를 시작합니다!\n", name);
    return 0;
}

    실행 결과: 

    플레이어 이름을 입력하세요: 민수
민수님, MBTI 테스트를 시작합니다!

    Step 2: 나이도 함께 받아보기¶

    #include <stdio.h>

int main(void) {
    char name[20];
    int age;

    printf("=== MBTI 성격 유형 테스트 ===\n");
    printf("이름: ");
    scanf("%s", name);
    printf("나이: ");
    scanf("%d", &age);  // 정수라 & 붙임!

    printf("\n%s님(%d세), 환영합니다! 테스트를 시작할게요.\n", name, age);
    return 0;
}

    실행 결과: 

    === MBTI 성격 유형 테스트 ===
이름: 민수
나이: 25

민수님(25세), 환영합니다! 테스트를 시작할게요.

    📝 전체 코드¶

    위 Step 2의 코드가 이번 챕터의 완성 코드입니다. 복사해서 바로 실행해 보세요! 🎮

    ⚠️ 주의할 점¶

    • %d에는 & 필수, %s(char 배열)에는 & 불필요 — 가장 흔한 실수예요!
    • scanf("%s", name)은 공백 전까지만 읽어요. "홍 길동"을 입력하면 "홍"만 저장됩니다.

    ✅ 점검하기¶

    1. 정수를 입력받을 때 올바른 코드는?

    정답 확인 `scanf("%d", &num);` — 서식 지정자 `%d`와 변수 앞에 `&`를 붙여야 합니다.

    2. char 배열로 문자열을 입력받을 때 &를 붙이지 않는 이유는?

    정답 확인 배열 이름 자체가 이미 주소를 가리키기 때문입니다. 자세한 원리는 7차시에서 배워요!
