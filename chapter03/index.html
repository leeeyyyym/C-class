    if-else로 갈림길 만들기 — 질문과 선택¶

    Part 2: 게임 로직 만들기 — 조건문과 반복문

    🎯 이 장에서 배우는 것¶

    • if, else if, else 문법을 이해하고 올바르게 작성할 수 있다
    • 비교 연산자(==, !=, <, >)를 조건문에 활용할 수 있다
    • 사용자 입력에 따라 다른 메시지를 출력하는 분기 구조를 구현할 수 있다

    📚 핵심 개념¶

    개념: 조건문 (if-else)¶

    비유로 시작 🚦

    조건문은 마치 갈림길의 이정표와 같아요. "비가 오면 우산을 들고, 안 오면 그냥 나간다" — 이렇게 상황에 따라 다른 행동을 하는 것이 조건문입니다.

    정확한 정의

    조건문은 주어진 조건이 참(true)이면 해당 코드 블록을 실행하고, 거짓(false)이면 건너뛰거나 다른 블록을 실행하는 구조입니다.

    C언어 기본 형태

    if (조건) {
    // 조건이 참일 때 실행
} else if (다른 조건) {
    // 위 조건은 거짓이고, 이 조건이 참일 때
} else {
    // 위 조건 모두 거짓일 때
}

    💡 파이썬과의 차이: 파이썬은 if 조건: 이지만, C언어는 조건을 소괄호 ()로 감싸고, 코드 블록을 중괄호 {}로 묶어야 합니다!

    비교 연산자 — 조건을 만드는 도구

    • == → 같다 (대입 =과 헷갈리지 마세요!)
    • != → 같지 않다
    • <, > → 작다, 크다
    • <=, >= → 작거나 같다, 크거나 같다
    flowchart TD A["사용자 입력 받기"] --> B{"answer == 1?"} B -- 참 --> C["E 점수 +1"] B -- 거짓 --> D{"answer == 2?"} D -- 참 --> E["I 점수 +1"] D -- 거짓 --> F["잘못된 입력 안내"]

    🔨 따라하기¶

    Step 1: 첫 번째 MBTI 질문 만들기¶

    2장에서 배운 scanf를 활용해, 질문에 대한 답을 받고 분기해 봅시다.

    코드:

    #include <stdio.h>

int main(void) {
    int answer;  // 사용자의 선택을 저장할 변수

    printf("=== MBTI 테스트 ===\n");
    printf("Q1. 파티에 가면?\n");
    printf("1: 새로운 사람과 적극적으로 대화한다\n");
    printf("2: 아는 사람 옆에서 조용히 있는다\n");
    printf("선택 (1 또는 2): ");
    scanf("%d", &answer);

    if (answer == 1) {
        printf("→ 외향형(E) 성향입니다!\n");
    } else if (answer == 2) {
        printf("→ 내향형(I) 성향입니다!\n");
    } else {
        printf("→ 1 또는 2만 입력해주세요.\n");
    }

    return 0;
}

    실행 결과 (1을 입력한 경우):

    === MBTI 테스트 ===
Q1. 파티에 가면?
1: 새로운 사람과 적극적으로 대화한다
2: 아는 사람 옆에서 조용히 있는다
선택 (1 또는 2): 1
→ 외향형(E) 성향입니다!

    Step 2: 점수를 변수로 관리하기¶

    실제 MBTI 테스트처럼, 선택에 따라 점수를 누적하는 방식으로 발전시켜 봅시다.

    코드:

    #include <stdio.h>

int main(void) {
    int answer;
    int e_score = 0;  // 외향 점수
    int i_score = 0;  // 내향 점수

    // Q1
    printf("Q1. 파티에 가면?\n");
    printf("1: 새로운 사람과 대화  2: 아는 사람과 대화\n");
    printf("선택: ");
    scanf("%d", &answer);

    if (answer == 1) {
        e_score = e_score + 1;  // E 점수 1점 추가
    } else {
        i_score = i_score + 1;  // I 점수 1점 추가
    }

    // 현재 점수 확인
    printf("\n현재 점수 → E: %d점, I: %d점\n", e_score, i_score);

    if (e_score > i_score) {
        printf("지금까지 결과: 외향형(E)\n");
    } else {
        printf("지금까지 결과: 내향형(I)\n");
    }

    return 0;
}

    실행 결과 (2를 입력한 경우):

    Q1. 파티에 가면?
1: 새로운 사람과 대화  2: 아는 사람과 대화
선택: 2

현재 점수 → E: 0점, I: 1점
지금까지 결과: 내향형(I)

    🎉 축하해요! 이제 질문 → 입력 → 분기 → 점수 반영이라는 MBTI 테스트의 핵심 흐름이 완성되었습니다.

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int answer;
    int e_score = 0;
    int i_score = 0;

    printf("=== MBTI 테스트 ===\n\n");

    printf("Q1. 파티에 가면?\n");
    printf("1: 새로운 사람과 적극적으로 대화한다\n");
    printf("2: 아는 사람 옆에서 조용히 있는다\n");
    printf("선택: ");
    scanf("%d", &answer);

    if (answer == 1) {
        e_score = e_score + 1;
        printf("→ 외향적 선택! E +1\n");
    } else if (answer == 2) {
        i_score = i_score + 1;
        printf("→ 내향적 선택! I +1\n");
    } else {
        printf("→ 잘못된 입력입니다.\n");
    }

    printf("\n[결과] E: %d점 / I: %d점\n", e_score, i_score);

    return 0;
}

    ⚠️ 주의할 점¶

    • =와 ==을 혼동하지 마세요! if (answer = 1)이라고 쓰면 "대입"이 되어 항상 참으로 실행됩니다. 비교할 때는 반드시 == 두 개!
    • 중괄호 {} 생략 주의: if 아래 코드가 한 줄이면 중괄호를 생략할 수 있지만, 초보 때는 항상 써주는 습관이 버그를 예방합니다.

    ✅ 점검하기¶

    1. 다음 코드에서 잘못된 부분은?

    if answer == 1 {
    printf("E!\n");
}
    정답 확인 조건을 **소괄호로 감싸야** 합니다. `if (answer == 1)` 이 올바른 문법입니다.

    2. if (answer = 2)와 if (answer == 2)의 차이는?

    정답 확인 `answer = 2`는 answer에 2를 **대입**하는 것이고, `answer == 2`는 answer가 2인지 **비교**하는 것입니다. 조건문에서는 `==`를 써야 합니다.

    3. else if는 언제 사용하나요?

    정답 확인 첫 번째 if 조건이 거짓일 때 **추가 조건을 검사**하고 싶을 때 사용합니다. 예: 입력이 1도 2도 아닌 경우를 처리할 때.
