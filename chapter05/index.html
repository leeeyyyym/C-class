    📚 핵심 개념¶

    개념: for문¶

    비유로 시작 🎠

    놀이공원 회전문을 떠올려보세요. 회전문은 세 가지가 정해져 있죠.

    • 출발 위치 → 초기식: int i = 0 (0번부터 시작!)
    • 몇 바퀴 돌지 → 조건식: i < 4 (4보다 작을 동안 계속)
    • 한 칸씩 전진 → 증감식: i++ (한 바퀴 돌 때마다 +1)

    정확한 정의

    C의 for문은 정해진 횟수만큼 코드를 반복 실행하는 구문입니다.

    for (int i = 0; i < 4; i++) {
    printf("질문 %d번\n", i + 1);
}

    파이썬과 비교 🐍

    파이썬에서는 이렇게 썼죠?

    for i in range(4):
    print(f"질문 {i+1}번")

    C에서는 range(4) 대신 세 부분을 직접 작성합니다. 더 명시적이지만, 그만큼 구조가 눈에 보여서 오히려 명확해요!

    flowchart LR A["Python: for i in range(4)"] --- B["시작·끝·증가가 range 안에 숨어있음"] C["C: for(int i=0; i<4; i++)"] --- D["시작·끝·증가를 직접 명시"]

    💡 while문도 있어요! while(조건)은 파이썬의 while 조건:과 거의 같습니다. 횟수가 정해져 있으면 for, 언제 끝날지 모르면 while — 이 기준은 파이썬과 동일해요.

    🔨 따라하기¶

    Step 1: 4번 반복해서 질문 출력하기¶

    #include <stdio.h>

int main(void) {
    char answer;

    // 질문 1: E/I
    printf("Q1. 새로운 사람을 만나면 에너지가 충전된다 (Y/N): ");
    scanf(" %c", &answer);

    // 질문 2: S/N
    printf("Q2. 구체적인 사실이 상상보다 중요하다 (Y/N): ");
    scanf(" %c", &answer);

    // 질문 3: T/F
    printf("Q3. 결정할 때 감정보다 논리를 우선한다 (Y/N): ");
    scanf(" %c", &answer);

    // 질문 4: J/P
    printf("Q4. 계획을 세우고 실행하는 편이다 (Y/N): ");
    scanf(" %c", &answer);

    return 0;
}

    잠깐, 이거 복사-붙여넣기 4번이네요! 😫 패턴이 똑같으니 for문으로 바꿔봅시다.

    Step 2: for문으로 개선하기¶

    #include <stdio.h>

int main(void) {
    char answer;

    for (int i = 1; i <= 4; i++) {
        // 아직 배열을 안 배워서 if로 구분합니다
        if (i == 1) printf("Q%d. 새로운 사람을 만나면 에너지가 충전된다 (Y/N): ", i);
        if (i == 2) printf("Q%d. 구체적인 사실이 상상보다 중요하다 (Y/N): ", i);
        if (i == 3) printf("Q%d. 결정할 때 감정보다 논리를 우선한다 (Y/N): ", i);
        if (i == 4) printf("Q%d. 계획을 세우고 실행하는 편이다 (Y/N): ", i);

        scanf(" %c", &answer);
        printf(">> %d번 응답: %c\n\n", i, answer);
    }

    printf("모든 질문 완료!\n");
    return 0;
}

    실행 결과: 

    Q1. 새로운 사람을 만나면 에너지가 충전된다 (Y/N): Y
>> 1번 응답: Y

Q2. 구체적인 사실이 상상보다 중요하다 (Y/N): N
>> 2번 응답: N

Q3. 결정할 때 감정보다 논리를 우선한다 (Y/N): Y
>> 3번 응답: Y

Q4. 계획을 세우고 실행하는 편이다 (Y/N): N
>> 4번 응답: N

모든 질문 완료!

    scanf와 printf 부분이 한 번만 작성되어 깔끔해졌어요! 🎉

    📝 전체 코드¶

int main(void) {
    char answer;

    for (int i = 1; i <= 4; i++) {
        if (i == 1) printf("Q%d. 새로운 사람을 만나면 에너지가 충전된다 (Y/N): ", i);
        if (i == 2) printf("Q%d. 구체적인 사실이 상상보다 중요하다 (Y/N): ", i);
        if (i == 3) printf("Q%d. 결정할 때 감정보다 논리를 우선한다 (Y/N): ", i);
        if (i == 4) printf("Q%d. 계획을 세우고 실행하는 편이다 (Y/N): ", i);

        scanf(" %c", &answer);
        printf(">> %d번 응답: %c\n\n", i, answer);
    }

    printf("모든 질문 완료!\n");
    return 0;
}

    ⚠️ 주의할 점¶

    • i++는 i = i + 1의 축약입니다. 파이썬에는 ++ 연산자가 없어서 낯설 수 있지만, C에서는 매우 자주 씁니다!
    • 질문마다 if를 쓰는 건 임시 방편이에요. 다음 장에서 배열을 배우면 질문 목록을 한 곳에 담아 훨씬 깔끔하게 만들 수 있습니다.

    ✅ 점검하기¶

    1. for (int i = 0; i < 3; i++)는 몇 번 반복될까요?

    정답 확인3번 (i가 0, 1, 2일 때 실행되고 i가 3이 되면 조건 i < 3이 거짓이라 종료)

    2. 파이썬의 for i in range(4)를 C로 바꾸면?

    정답 확인for (int i = 0; i < 4; i++) — range(4)는 0부터 3까지이므로 초기값 0, 조건 i < 4, 증감 i++

    3. for문의 세 구성 요소를 순서대로 말해보세요.

    정답 확인초기식(시작값 설정) → 조건식(계속할지 판단) → 증감식(값 변화)
