    switch-case — 깔끔한 다중 선택¶

    🎯 이 장에서 배우는 것¶

    • switch-case 문의 구조와 break의 역할을 설명할 수 있다
    • MBTI 게임에 메뉴 선택 기능을 switch(match-case)로 구현할 수 있다
    • if-else와 switch-case의 사용 상황을 구분할 수 있다

    📚 핵심 개념¶

    개념: switch-case (파이썬의 match-case)¶

    1. 비유로 시작 🎰

    switch-case는 마치 자판기 버튼과 같아요. 1번을 누르면 커피, 2번을 누르면 주스, 3번을 누르면 물이 나오죠. 버튼 번호에 따라 딱 하나의 결과로 연결됩니다.

    if-else로 이걸 처리하면 "1번이면? 아니면 2번이면? 아니면 3번이면?" 하고 줄줄이 비교해야 하는데, switch-case는 번호표를 딱 보고 바로 이동하는 느낌이에요.

    2. 정확한 정의

    하나의 값을 여러 경우(case)와 비교해서, 일치하는 경우의 코드를 실행하는 제어문입니다.

    💡 파이썬 버전 참고: 전통적인 switch-case는 C, Java 등에 있고, 파이썬에는 오랫동안 없었습니다. Python 3.10부터 match-case 문법이 추가되었어요! 구조는 거의 같으니 걱정 마세요.

    3. 예시로 확인

    menu = 1

match menu:
    case 1:
        print("테스트 시작!")
    case 2:
        print("MBTI 설명 보기")
    case 3:
        print("종료합니다")
    case _:
        print("잘못된 입력입니다")
    • match 값: → 비교할 값을 지정
    • case 1: → 값이 1이면 이 블록 실행
    • case _: → 어디에도 해당하지 않을 때 (기본값, default)
    flowchart TD A["menu 값 확인"] --> B{"case 1?"} B -- Yes --> C["테스트 시작!"] B -- No --> D{"case 2?"} D -- Yes --> E["MBTI 설명 보기"] D -- No --> F{"case 3?"} F -- Yes --> G["종료합니다"] F -- No --> H["잘못된 입력 (case _)"]

    🔑 break는? C/Java에서는 break를 안 쓰면 다음 case로 흘러내리는(fall-through) 문제가 생기지만, 파이썬 match-case는 자동으로 멈추기 때문에 break가 필요 없습니다!

    🔨 따라하기¶

    Step 1: MBTI 게임 메뉴 만들기¶

    print("=== MBTI 성격 테스트 ===")
print("1. 테스트 시작")
print("2. MBTI란?")
print("3. 종료")

choice = int(input("메뉴를 선택하세요: "))

match choice:
    case 1:
        print("🎮 테스트를 시작합니다!")
    case 2:
        print("📖 MBTI는 16가지 성격 유형 분류 체계입니다.")
    case 3:
        print("👋 다음에 또 만나요!")
    case _:
        print("⚠️ 1~3 중에서 골라주세요.")

    실행 결과 (2를 입력했을 때): 

    === MBTI 성격 테스트 ===
1. 테스트 시작
2. MBTI란?
3. 종료
메뉴를 선택하세요: 2
📖 MBTI는 16가지 성격 유형 분류 체계입니다.

    Step 2: 같은 기능을 if-else로 비교해 보기¶

    # 같은 동작을 if-else로 쓰면?
if choice == 1:
    print("🎮 테스트를 시작합니다!")
elif choice == 2:
    print("📖 MBTI는 16가지 성격 유형 분류 체계입니다.")
elif choice == 3:
    print("👋 다음에 또 만나요!")
else:
    print("⚠️ 1~3 중에서 골라주세요.")

    둘 다 동작은 같지만, 선택지가 많아질수록 match-case가 더 읽기 편합니다. 반면 if choice > 5 같은 범위 조건에는 if-else가 적합해요.

    • match-case → 정확한 값 비교 (메뉴 번호, 요일, 등급 등)
    • if-else → 범위·복합 조건 (점수 구간, 크기 비교 등)

    📝 전체 코드¶

    # MBTI 게임 - 메뉴 선택 (match-case 버전)
print("=== MBTI 성격 테스트 ===")
print("1. 테스트 시작")
print("2. MBTI란?")
print("3. 종료")

choice = int(input("메뉴를 선택하세요: "))

match choice:
    case 1:
        print("🎮 테스트를 시작합니다!")
    case 2:
        print("📖 MBTI는 16가지 성격 유형 분류 체계입니다.")
    case 3:
        print("👋 다음에 또 만나요!")
    case _:
        print("⚠️ 1~3 중에서 골라주세요.")

    ⚠️ 주의할 점¶

    • Python 3.10 이상 필요! 그보다 낮은 버전에서는 match를 쓸 수 없으니 python --version으로 확인하세요. 3.10 미만이라면 if-elif-else로 대체하면 됩니다.
    • case _:를 빼먹지 마세요. 사용자는 언제든 예상 밖의 값을 입력할 수 있어요. 기본 처리가 없으면 아무 반응 없이 넘어가 버립니다.

    ✅ 점검하기¶

    1. match-case에서 case _:의 역할은 무엇인가요?

    정답 확인 어떤 case에도 일치하지 않을 때 실행되는 **기본(default) 처리**입니다. if-else에서 마지막 `else`와 같은 역할이에요.

    2. "점수가 80 이상이면 A, 60 이상이면 B, 나머지는 C" — 이 조건에는 match-case와 if-else 중 무엇이 적합할까요?

    정답 확인 **if-else**가 적합합니다. match-case는 정확한 값 비교에 강하고, 범위 비교(`>= 80`)에는 if-elif-else가 자연스럽습니다.

    3. C/Java의 switch에서 break를 빼먹으면 생기는 현상의 이름은?

    정답 확인 **fall-through**(폴스루)입니다. 다음 case로 흘러내려서 의도하지 않은 코드까지 실행됩니다. 파이썬의 match-case는 이 문제가 없어요!
