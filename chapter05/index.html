    함수로 기능 분리하기 — 나만의 블록 만들기¶

    Part 3: 코드를 정리하자 — 함수

    🎯 이 장에서 배우는 것¶

    • C언어 함수의 선언·정의·호출 흐름을 이해하고 직접 작성할 수 있다
    • 매개변수와 반환값의 역할을 설명할 수 있다
    • MBTI 게임 코드를 함수로 분리하여 정리할 수 있다

    📚 핵심 개념¶

    개념: 함수 (Function)¶

    1. 비유로 시작 🍳

    함수는 마치 레시피 카드와 같아요. "토마토 파스타" 레시피 카드에는 재료(매개변수), 조리 과정(함수 본문), 완성 요리(반환값)가 적혀 있죠. 한 번 카드를 만들어 두면, "토마토 파스타 해줘!"라고 이름만 부르면(호출) 됩니다.

    2. 정확한 정의

    C언어 함수는 세 단계로 나뉩니다.

    • 선언(프로토타입): "이런 함수가 있을 거야"라고 미리 알려주기 → int add(int a, int b);
    • 정의: 실제 동작을 작성하기 → { return a + b; }
    • 호출: 함수를 실행하기 → add(3, 5);

    파이썬의 def와 비교하면 이렇게 다릅니다:

    flowchart LR subgraph Python A["def add(a, b):\n return a + b"] end subgraph C언어 B["선언: int add(int a, int b);"] C["정의: int add(int a, int b) {\n return a + b;\n}"] end A -. "C에서는 두 단계로" .-> B B --> C

    💡 핵심 차이: C언어는 반환형(int, void 등)을 반드시 명시하고, 매개변수에도 자료형을 붙여야 합니다!

    3. 예시로 확인

    // 선언 (main 위에)
int add(int a, int b);

int main() {
    int result = add(3, 5);  // 호출
    printf("%d\n", result);
    return 0;
}

// 정의 (main 아래)
int add(int a, int b) {
    return a + b;
}

    반환할 것이 없으면 void를 씁니다 → void sayHello() { printf("Hello!\n"); }

    🔨 따라하기¶

    Step 1: 질문 출력 함수 만들기¶

    MBTI 게임에서 질문을 출력하고 답을 받는 부분을 함수로 빼봅시다.

    #include <stdio.h>

// 선언
int askQuestion(char question[]);

int main() {
    int score = 0;

    // 호출 — 이름만 부르면 끝!
    score += askQuestion("혼자 있는 시간이 편하다 (1:Yes / 0:No): ");
    score += askQuestion("사람 많은 곳이 피곤하다 (1:Yes / 0:No): ");

    printf("내향 점수: %d\n", score);
    return 0;
}

// 정의
int askQuestion(char question[]) {
    int answer;
    printf("%s", question);
    scanf("%d", &answer);
    return answer;  // 입력값을 돌려줌
}

    실행 결과: 

    혼자 있는 시간이 편하다 (1:Yes / 0:No): 1
사람 많은 곳이 피곤하다 (1:Yes / 0:No): 1
내향 점수: 2

    Step 2: 결과 판정 함수 추가하기¶

    점수를 받아 결과를 출력하는 함수를 더해봅시다.

    // 선언 추가
void printResult(int score);

// main 안에서 호출
printResult(score);

// 정의
void printResult(int score) {
    if (score >= 2) {
        printf("당신은 I(내향)에 가깝습니다!\n");
    } else {
        printf("당신은 E(외향)에 가깝습니다!\n");
    }
}

    🎉 main()이 훨씬 깔끔해졌죠? 이것이 함수로 기능을 분리하는 핵심 이유입니다!

    📝 전체 코드¶

    #include <stdio.h>

// 함수 선언 (레시피 목록)
int askQuestion(char question[]);
void printResult(int score);

int main() {
    int score = 0;

    printf("=== 간단 MBTI 테스트 ===\n");
    score += askQuestion("혼자 있는 시간이 편하다 (1:Yes / 0:No): ");
    score += askQuestion("사람 많은 곳이 피곤하다 (1:Yes / 0:No): ");
    score += askQuestion("약속 후 충전 시간이 필요하다 (1:Yes / 0:No): ");

    printResult(score);
    return 0;
}

// 함수 정의 (실제 조리 과정)
int askQuestion(char question[]) {
    int answer;
    printf("%s", question);
    scanf("%d", &answer);
    return answer;
}

void printResult(int score) {
    if (score >= 2) {
        printf("결과: I(내향)에 가깝습니다!\n");
    } else {
        printf("결과: E(외향)에 가깝습니다!\n");
    }
}

    ⚠️ 주의할 점¶

    • 선언을 빼먹으면? main()보다 아래에 정의된 함수를 호출하면 컴파일 에러가 납니다. 선언(프로토타입)을 main() 위에 꼭 적어주세요!
    • void 함수에 return 값; 쓰면 안 돼요. 반환할 것이 없으면 void, 있으면 해당 자료형을 정확히 맞춰주세요.

    ✅ 점검하기¶

    1. C언어 함수에서 반드시 명시해야 하지만, 파이썬 def에서는 쓰지 않는 것은?

    정답 확인반환형(int, void 등)과 매개변수의 자료형입니다. 파이썬은 자료형을 생략하지만, C는 반드시 적어야 합니다.

    2. 함수 선언(프로토타입)은 왜 main() 위에 적을까요?

    정답 확인C 컴파일러는 코드를 위에서 아래로 읽기 때문에, main()에서 호출할 함수를 미리 알려줘야 합니다. 선언이 없으면 "이 함수가 뭔지 모르겠다"는 에러가 발생합니다.

    3. void printResult(int score) 에서 void는 무슨 뜻일까요?

    정답 확인이 함수는 값을 돌려주지 않는다(반환값이 없다)는 뜻입니다. 출력만 하고 끝나는 함수에 사용합니다.
