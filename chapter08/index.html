    포인터 맛보기 — 주소라는 개념 이해하기¶

    🎯 이 장에서 배우는 것¶

    • 변수의 메모리 주소 개념과 & 연산자의 역할을 설명할 수 있다
    • 포인터 변수(*)의 기본 선언과 역참조를 체험할 수 있다
    • scanf에서 &를 써야 하는 이유를 이해할 수 있다

    📚 핵심 개념¶

    개념: 메모리 주소와 포인터¶

    1. 비유로 시작 🏢

    컴퓨터 메모리는 거대한 사물함 보관소와 같아요. 변수를 만들면 사물함 하나가 배정되고, 각 사물함에는 고유 번호(주소)가 붙어 있습니다.

    • int score = 90; → 사물함 안에 90이 들어 있음
    • &score → 그 사물함의 번호표 (예: 0x7ffd1234)
    • 포인터 변수 → 다른 사물함의 번호를 적어둔 메모지 📝
    flowchart LR A["변수 score\n값: 90"] -->|"&score"| B["주소: 0x7ffd1234"] C["포인터 ptr\n값: 0x7ffd1234"] -->|"*ptr"| A

    2. 정확한 정의

    • & (주소 연산자): 변수 앞에 붙여서 그 변수의 메모리 주소를 알려줌
    • 포인터 변수: 주소를 저장하는 특별한 변수 (int *ptr;)
    • * (역참조 연산자): 포인터가 가리키는 주소로 찾아가 값을 꺼냄

    3. 예시로 확인 — scanf의 비밀!

    그동안 써왔던 scanf("%d", &score);에서 &는 "score의 사물함 번호를 알려줄게, 거기에 값을 넣어줘!"라는 뜻이었습니다. 주소를 알려줘야 scanf가 올바른 사물함에 값을 저장할 수 있으니까요! 🎯

    🔨 따라하기¶

    Step 1: 주소 출력해 보기¶

    #include <stdio.h>

int main(void) {
    int score = 90;

    printf("값:  %d\n", score);   // 사물함 안의 내용물
    printf("주소: %p\n", &score); // 사물함 번호
    return 0;
}

    실행 결과 (주소는 실행마다 달라요): 

    값:  90
주소: 0x7ffd5e3a1c

    💡 %p는 주소를 출력하는 서식 지정자예요.

    Step 2: 포인터로 값 꺼내보기¶

    #include <stdio.h>

int main(void) {
    int score = 90;
    int *ptr = &score;  // ptr에 score의 주소를 저장

    printf("ptr이 가리키는 값: %d\n", *ptr);  // 역참조

    *ptr = 100;  // 포인터를 통해 값 변경!
    printf("변경 후 score: %d\n", score);
    return 0;
}

    실행 결과: 

    ptr이 가리키는 값: 90
변경 후 score: 100

    *ptr = 100;은 메모지에 적힌 사물함 번호로 찾아가서 내용물을 바꾼 것입니다! ✨

    📝 전체 코드¶

    #include <stdio.h>

int main(void) {
    int score = 90;
    int *ptr = &score;

    // 주소와 값 확인
    printf("score의 값:  %d\n", score);
    printf("score의 주소: %p\n", &score);
    printf("ptr의 값(주소): %p\n", ptr);
    printf("ptr이 가리키는 값: %d\n", *ptr);

    // 포인터로 값 변경
    *ptr = 100;
    printf("변경 후 score: %d\n", score);

    return 0;
}

    ⚠️ 주의할 점¶

    • scanf에서 &를 빼먹으면 엉뚱한 주소에 값을 쓰게 되어 프로그램이 죽을 수 있어요! 🚨
    • 포인터는 강력하지만 위험할 수 있습니다. 지금은 "주소라는 게 있구나" 정도만 기억하면 충분해요.

    ✅ 점검하기¶

    1. &score는 무엇을 의미하나요?

    정답 확인변수 score가 저장된 메모리의 주소(사물함 번호)를 의미합니다.

    2. int *ptr = &score; 후 *ptr은 어떤 값인가요?

    정답 확인ptr이 가리키는 주소(score의 주소)에 저장된 값, 즉 score의 값과 같습니다.

    3. scanf("%d", &num);에서 &가 필요한 이유는?

    정답 확인scanf가 입력받은 값을 num의 메모리 주소에 저장해야 하므로, 주소를 알려줘야 합니다.
