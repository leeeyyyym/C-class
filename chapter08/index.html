    함수의 기본 — 코드를 상자에 담기¶

    🎯 이 장에서 배우는 것¶

    • C언어에서 함수를 선언하고 정의하는 문법(반환형, 매개변수, return)을 작성할 수 있다
    • 파이썬의 def와 C의 함수 정의 방식을 비교할 수 있다
    • MBTI 게임의 인트로 출력을 별도 함수로 분리할 수 있다

    📚 핵심 개념¶

    개념: 함수¶

    비유로 시작 🍱

    함수는 도시락 칸과 같아요. 밥, 반찬, 디저트를 한 통에 다 넣으면 뒤죽박죽이지만, 칸칸이 나누면 깔끔하죠. 코드도 마찬가지입니다. 지금까지 main 안에 모든 코드를 넣었는데, 역할별로 함수에 나눠 담으면 훨씬 읽기 좋아집니다.

    정확한 정의

    함수는 특정 작업을 수행하는 코드 묶음입니다. C에서는 반드시 반환형과 매개변수 타입을 명시해야 합니다.

    반환형 함수이름(매개변수) {
    // 할 일
    return 값;  // 반환형이 void면 생략 가능
}

    파이썬 vs C 비교

    graph LR A["🐍 파이썬"] --> B["def greet():<br/> print('Hello')"] C["⚙️ C언어"] --> D["void greet(void) {<br/> printf('Hello');<br/>}"]

    C에서 달라지는 핵심 두 가지: - void → "돌려줄 값 없음"을 명시 (파이썬은 생략 가능했죠) - 매개변수에도 타입 → int age 처럼 타입을 꼭 적어야 합니다

    🔨 따라하기¶

    Step 1: 타이틀 출력 함수 만들기¶

    게임 타이틀을 출력하는 부분을 함수로 빼봅시다.

    #include <stdio.h>

// 함수 정의: 반환 없음(void), 매개변수 없음(void)
void printTitle(void) {
    printf("========================\n");
    printf("  나만의 MBTI 테스트!\n");
    printf("========================\n");
}

int main(void) {
    printTitle();  // 함수 호출 — 이 한 줄이면 끝!
    return 0;
}

    실행 결과: 

    ========================
  나만의 MBTI 테스트!
========================

    💡 main이 훨씬 짧아졌죠? 타이틀 디자인을 바꾸고 싶으면 printTitle만 수정하면 됩니다.

    Step 2: 이름을 받는 함수 추가하기¶

    이번엔 매개변수와 return을 써봅시다. 이름을 입력받고, 첫 글자를 돌려주는 함수입니다.

    #include <stdio.h>

void printTitle(void) {
    printf("========================\n");
    printf("  나만의 MBTI 테스트!\n");
    printf("========================\n");
}

// char 반환, char 배열을 매개변수로 받음
char getName(char name[], int size) {
    printf("이름을 입력하세요: ");
    fgets(name, size, stdin);
    return name[0];  // 첫 글자 반환
}

int main(void) {
    char name[50];

    printTitle();
    char initial = getName(name, 50);
    printf("환영합니다! 첫 글자: %c\n", initial);

    return 0;
}

    실행 결과: 

    ========================
  나만의 MBTI 테스트!
========================
이름을 입력하세요: 민수
환영합니다! 첫 글자: 민

    📝 전체 코드¶

    #include <stdio.h>

void printTitle(void) {
    printf("========================\n");
    printf("  나만의 MBTI 테스트!\n");
    printf("========================\n");
}

char getName(char name[], int size) {
    printf("이름을 입력하세요: ");
    fgets(name, size, stdin);
    return name[0];
}

int main(void) {
    char name[50];

    printTitle();
    char initial = getName(name, 50);
    printf("환영합니다! 첫 글자: %c\n", initial);

    return 0;
}

    ⚠️ 주의할 점¶

    1. 함수는 호출 전에 정의하거나 선언하세요. main 아래에 함수를 쓰면 컴파일러가 "이 함수 뭔데?" 하고 에러를 냅니다. 위에 먼저 쓰거나, 맨 위에 void printTitle(void); 같은 선언(프로토타입)을 추가하세요.

    2. void를 빠뜨리지 마세요. 돌려줄 값이 없으면 반환형에 void, 받을 값이 없으면 매개변수에 void — C는 "없음"도 명시하는 언어입니다.

    ✅ 점검하기¶

    1. 아무것도 반환하지 않고 매개변수도 없는 C 함수의 형태는?

    정답 확인 `void 함수이름(void) { ... }` — 반환형과 매개변수 모두 `void`로 적습니다.

    2. 파이썬의 def greet(name): 을 C로 바꾸면 무엇이 추가되어야 할까요?

    정답 확인 반환형(예: `void`)과 매개변수의 타입(예: `char name[]`)을 명시해야 합니다. → `void greet(char name[]) { ... }`

    3. 함수를 main 아래에 정의했더니 에러가 났습니다. 해결 방법은?

    정답 확인 파일 맨 위에 **함수 프로토타입**(선언)을 추가합니다. 예: `void printTitle(void);`
