    함수 (2) — 함수 선언과 지역변수 이해하기¶

    🎯 이 장에서 배우는 것¶

    • 함수를 main 앞에 선언(프로토타입)하는 방법을 설명할 수 있다
    • 지역변수의 개념과 유효 범위(스코프)를 이해할 수 있다
    • 함수끼리 같은 변수명을 써도 충돌하지 않는 이유를 설명할 수 있다

    📚 핵심 개념¶

    개념 1: 함수 선언 (프로토타입)¶

    왜 필요한가요? 🤔 C 언어는 코드를 위에서 아래로 읽습니다. 그래서 main보다 아래에 함수를 정의하면 컴파일러가 인식하지 못해 오류를 냅니다.

    방법설명예시
    ① 함수를 main 앞에 정의짧은 함수일 때 편리앞 챕터 방식
    ② 프로토타입 선언 후 정의실무에서 권장이번 챕터 방식 ✅

    프로토타입이란? — "이런 함수가 나중에 나올 거야!"라고 미리 알려주는 예고편입니다.

    // 프로토타입 (세미콜론으로 끝납니다!)
int add(int a, int b);

int main(void) {
    int result = add(3, 5);   // 컴파일러가 add를 알고 있어서 OK ✅
    printf("%d\n", result);
    return 0;
}

// 실제 정의는 main 아래에
int add(int a, int b) {
    return a + b;
}

    개념 2: 지역변수와 유효 범위 (스코프)¶

    비유로 시작 🏠 각 함수는 자신만의 독립된 방입니다. 방 안에서 선언한 변수(지역변수)는 그 방 안에서만 존재하며, 다른 방에서는 보이지 않습니다.

    flowchart LR subgraph main_room["🏠 main 방"] MV["int score = 90"] end subgraph add_room["🏠 add 방"] AV["int score = 0\n(전혀 다른 변수!)"] end main_room -.->|"서로 안 보임 🚫"| add_room 
    void showScore(void) {
    int score = 100;       // showScore 방의 score
    printf("%d\n", score);
}

int main(void) {
    int score = 90;        // main 방의 score
    showScore();
    printf("%d\n", score); // 90 출력 — main의 score는 그대로!
    return 0;
}

    💡 핵심: 함수가 끝나면 그 안의 지역변수는 사라집니다. 함수가 호출될 때마다 새로 만들어집니다.

    🔨 따라하기¶

    Step 1: 오류 체험

    #include <stdio.h>
int main(void) {
    greet(); // ❌ greet()가 아직 선언되지 않음!
    return 0;
}
void greet(void) { printf("안녕하세요!\n"); }

    Step 2: 프로토타입으로 해결

    #include <stdio.h>
void greet(void); // ✅ 프로토타입 선언

int main(void) {
    greet(); // 이제 작동!
    return 0;
}
void greet(void) { printf("안녕하세요!\n"); }

    📝 전체 코드 — 미니 계산기¶

    #include <stdio.h>

/* ---- 프로토타입 선언 ---- */
int add(int a, int b);
int subtract(int a, int b);
void printResult(int result);

int main(void) {
    int x = 20, y = 8;
    int sum  = add(x, y);
    int diff = subtract(x, y);

    printf("덧셈 결과: ");
    printResult(sum);
    printf("뺄셈 결과: ");
    printResult(diff);

    return 0;
}

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
void printResult(int result) { printf("%d\n", result); }

    ✅ 점검하기¶

    1. 프로토타입 선언이 필요한 이유는 무엇인가요?
      정답 확인C 언어는 위에서 아래로 읽기 때문에, 뒤에 나오는 함수를 미리 알려줘야 호출할 수 있습니다.
    2. 함수가 끝난 뒤 그 안의 지역변수는 어떻게 되나요?
      정답 확인메모리에서 사라지며, 다음 호출 때 새로 만들어집니다.
