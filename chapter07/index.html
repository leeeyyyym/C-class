    while 반복문과 게임 루프¶

    Part 2: 게임에 두뇌를 달자 — 조건문과 반복문

    🎯 이 장에서 배우는 것¶

    • while문의 동작 원리를 이해하고 사용할 수 있다
    • do-while 패턴으로 "다시 하기" 기능을 구현할 수 있다
    • 무한 루프 + break로 게임 루프를 만들 수 있다

    📚 핵심 개념¶

    개념: while 반복문¶

    비유로 시작 🚦

    while문은 마치 "신호등이 빨간불인 동안 계속 기다리기" 와 같아요. 언제 바뀔지 모르지만, 파란불이 되는 순간 기다림을 멈추죠.

    for문은 "5번 반복해!" 처럼 횟수가 정해져 있을 때 쓰고, while문은 "조건이 맞는 동안 계속!" 할 때 씁니다.

    정확한 정의

    while 조건:
    반복할 코드

    조건이 True인 동안 코드를 반복하고, False가 되면 멈춥니다.

    예시로 확인

    count = 3
while count > 0:
    print(f"카운트다운: {count}")
    count -= 1
print("🚀 발사!")

    카운트다운: 3
카운트다운: 2
카운트다운: 1
🚀 발사!

    개념: 무한 루프와 break¶

    게임은 플레이어가 "그만할래"라고 할 때까지 계속 돌아야 합니다. 이때 무한 루프 + break 조합을 씁니다.

    while True:        # 무한 반복!
    answer = input("계속? (y/n): ")
    if answer == "n":
        break      # 탈출!
print("종료!")

    💡 while True는 조건이 항상 참이라 영원히 반복합니다. break가 유일한 탈출구예요!

    flowchart TD A[while True 시작] --> B[게임 실행] B --> C{다시 할까요?} C -->|y| A C -->|n| D[break로 탈출] D --> E[프로그램 종료]

    🔨 따라하기¶

    Step 1: 숫자 맞히기 미니게임¶

    while문의 핵심을 체험해봅시다.

    import random

secret = random.randint(1, 10)  # 1~10 랜덤 숫자

while True:
    guess = int(input("숫자를 맞혀보세요 (1~10): "))
    if guess == secret:
        print("🎉 정답!")
        break  # 맞히면 탈출
    print("❌ 틀렸어요, 다시!")

print("게임 끝!")

    숫자를 맞혀보세요 (1~10): 3
❌ 틀렸어요, 다시!
숫자를 맞혀보세요 (1~10): 7
🎉 정답!
게임 끝!

    Step 2: MBTI 테스트에 "다시 하기" 추가¶

    이전 챕터의 MBTI 테스트를 게임 루프로 감싸봅시다. "일단 한 번은 실행하고, 끝나면 다시 할지 물어보는" 패턴입니다.

    while True:
    # --- MBTI 미니 테스트 ---
    print("\n🧠 초간단 MBTI 테스트!")

    q1 = input("주말에 뭐 할래? (a: 친구 만남 / b: 집에서 쉼): ")
    q2 = input("결정할 때? (a: 바로 직감 / b: 꼼꼼히 비교): ")

    result = ""
    result += "E" if q1 == "a" else "I"
    result += "F" if q2 == "a" else "T"

    print(f"\n✨ 당신의 유형: {result}")

    # --- 다시 하기 ---
    again = input("\n🔄 다시 하시겠습니까? (y/n): ")
    if again != "y":
        break

print("👋 테스트를 종료합니다!")

    🧠 초간단 MBTI 테스트!
주말에 뭐 할래? (a: 친구 만남 / b: 집에서 쉼): a
결정할 때? (a: 바로 직감 / b: 꼼꼼히 비교): b
✨ 당신의 유형: ET

🔄 다시 하시겠습니까? (y/n): y

🧠 초간단 MBTI 테스트!
...
🔄 다시 하시겠습니까? (y/n): n
👋 테스트를 종료합니다!

    🎮 이 "실행 → 다시 할지 묻기 → 반복/종료" 패턴이 바로 게임 루프의 핵심입니다!

    📝 전체 코드¶

    # MBTI 테스트 - 게임 루프 버전
while True:
    print("\n🧠 초간단 MBTI 테스트!")

    q1 = input("주말에 뭐 할래? (a: 친구 만남 / b: 집에서 쉼): ")
    q2 = input("결정할 때? (a: 바로 직감 / b: 꼼꼼히 비교): ")

    result = ""
    result += "E" if q1 == "a" else "I"
    result += "F" if q2 == "a" else "T"

    print(f"\n✨ 당신의 유형: {result}")

    again = input("\n🔄 다시 하시겠습니까? (y/n): ")
    if again != "y":
        break

print("👋 테스트를 종료합니다!")

    ⚠️ 주의할 점¶

    • 무한 루프 탈출구를 꼭 만드세요! while True를 쓰면서 break 조건을 빼먹으면 프로그램이 영원히 멈추지 않습니다. 만약 빠져나갈 수 없다면 Ctrl + C로 강제 종료하세요.
    • while 조건 변수 업데이트를 잊지 마세요! while count > 0:을 쓰면서 count -= 1을 안 넣으면 역시 무한 루프에 빠집니다.

    ✅ 점검하기¶

    1. while문과 for문은 언제 각각 사용하나요?

    정답 확인 for문은 반복 횟수가 정해져 있을 때(예: 5번 반복), while문은 조건이 만족하는 동안 반복할 때(예: 사용자가 종료할 때까지) 사용합니다.

    2. 아래 코드의 문제점은? 

    x = 5
while x > 0:
    print(x)

    정답 확인 x 값을 줄여주는 코드(x -= 1)가 없어서 x가 항상 5이므로 무한 루프에 빠집니다.

    3. while True + break 패턴은 어떤 상황에 유용한가요?

    정답 확인 일단 실행하고 나서 계속할지 물어보는 게임 루프에 유용합니다. 최소 1회 실행을 보장하면서, 사용자 입력에 따라 종료할 수 있습니다.
