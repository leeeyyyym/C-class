    Hello, C! — 개발 환경 준비와 첫 프로그램¶

    Part 1: C언어와의 첫 만남 — 게임의 시작 ⏱️ 약 20분

    🎯 이 장에서 배우는 것¶

    • C언어 개발 환경(온라인 IDE)을 열고 코드를 실행할 수 있다
    • printf를 사용하여 화면에 원하는 문장을 출력할 수 있다
    • C 프로그램의 기본 구조 4가지(#include, main, {}, ;)를 설명할 수 있다

    📚 핵심 개념¶

    개념: C 프로그램의 기본 구조¶

    1. 비유로 시작 ✉️

    C 프로그램은 공식 편지를 쓰는 것과 같아요.

    • 편지지 상단에 "보내는 곳"을 쓰듯 → #include <stdio.h> (도구 준비)
    • "본문 시작"을 알리듯 → int main() (프로그램 시작점)
    • 본문을 중괄호 {}로 감싸고 → 내용의 범위 표시
    • 문장 끝마다 마침표 대신 세미콜론 ; → 명령어의 끝 표시

    파이썬에서는 print("Hello")만 쓰면 되었지만, C는 이 편지 형식을 꼭 갖춰야 합니다.

    2. 정확한 정의

    graph TD A["#include &lt;stdio.h&gt;<br/>📦 도구 상자 열기"] --> B["int main( )<br/>🚪 프로그램의 입구"] B --> C["{ }<br/>📋 실행할 내용 묶기"] C --> D["printf(...);<br/>🖨️ 화면에 출력"] C --> E["return 0;<br/>✅ 프로그램 종료"]
    • #include <stdio.h> — printf 같은 입출력 기능이 들어있는 도구 상자
    • int main() — 컴퓨터가 "여기부터 시작!"하고 찾는 입구
    • { } — 실행할 코드를 담는 울타리
    • ; — 모든 명령문 끝에 붙이는 마침표

    3. 예시로 확인 — 파이썬 vs C 비교

    graph LR subgraph Python P["print('Hello, C!')"] end subgraph C C1["#include &lt;stdio.h&gt;"] --> C2["int main() {"] --> C3[" printf('Hello, C!');"] --> C4[" return 0;"] --> C5["}"] end

    C가 좀 더 길지만, 패턴은 항상 같아요. 한 번 익히면 매번 똑같이 쓰면 됩니다! 😊

    Step 2: 첫 프로그램 — MBTI 게임 타이틀 출력 🎮¶

    코드 입력창에 아래 코드를 그대로 입력하고 Run 버튼을 누르세요.

    #include <stdio.h>  // printf를 쓰기 위한 도구 상자

int main() {
    printf("=============================\n");
    printf("  나의 MBTI를 알아보자!\n");
    printf("=============================\n");
    return 0;  // 프로그램 정상 종료
}

    실행 결과: 

    =============================
  나의 MBTI를 알아보자!
=============================

    💡 \n이 뭐예요? — "줄 바꿈"을 의미합니다. 파이썬의 print()는 자동 줄 바꿈이지만, C의 printf는 직접 \n을 넣어야 해요.

    📝 전체 코드¶

    #include <stdio.h>

int main() {
    printf("=============================\n");
    printf("  나의 MBTI를 알아보자!\n");
    printf("=============================\n");
    return 0;
}

    ⚠️ 주의할 점¶

    • 세미콜론 ; 빠뜨리기 — C 초보자 에러 1위! 모든 명령문 끝에 ;을 꼭 확인하세요.
    • #include 빠뜨리기 — #include <stdio.h> 없이 printf를 쓰면 컴파일 에러가 납니다. 도구 상자를 안 열고 도구를 꺼내려는 것과 같아요!

    ✅ 점검하기¶

    1. #include <stdio.h>는 왜 필요한가요?

    정답 확인 `printf` 같은 입출력 함수를 사용하기 위한 도구 상자(헤더 파일)를 불러오는 것입니다. 이것 없이는 `printf`를 쓸 수 없어요.

    2. 아래 코드에서 에러가 나는 이유는? 

    printf("Hello")

    정답 확인 문장 끝에 세미콜론(`;`)이 빠져있습니다. `printf("Hello");`로 고쳐야 합니다.

    3. C에서 줄 바꿈을 하려면 어떻게 하나요?

    정답 확인 `printf` 안에 `\n`을 넣으면 됩니다. 예: `printf("첫째 줄\n둘째 줄\n");`
